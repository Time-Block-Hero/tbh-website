主动效果由玩家声明发动。本页提供设计稿的填写规格；发动权限和步骤以[4.5 主动能力](../actions.md#主动能力)为准。表中的“必填”针对完整设计稿，卡面可以引用已经定义的默认或关键词。

## 7.2.1 必填要素

先写清谁能够在何种局面发动，再写此次发动需要作什么选择、支付什么以及得到什么。

| 要素 | 含义与必填条件 | 选项或定义入口 | 省略时的处理 | 填写例 |
| --- | --- | --- | --- | --- |
| 来源与发动者 | 必填。指出哪张牌具有这项能力、谁有权使用。 | [对象字典](dictionary/targets.md) | 不由“你”猜测拥有者还是控制者。 | 战场上这张牌的控制者。 |
| 来源区域及有效条件 | 必填。列出来源的可用区域；额外要求没有则写“无”。既有封锁规则仍适用。 | [条件字典](dictionary/conditions.md) | 不默认所有区域都有效。 | 来源在战场；额外条件无。 |
| 操作窗口 | 必填，但可引用既定规则。 | [4.5](../actions.md#主动能力) | 引用默认：仅在自己的时动阶段主动使用。 | 按 4.5，不增加其他发动窗口。 |
| 发动成本 | 必填。明确成本种类、数量、支付者；不收费须写“无”。 | [成本字典](dictionary/costs.md) | 留白不能解释为购买标价或自动支付行动点。 | 无额外发动成本。 |
| 目标范围 | 需要目标时必填；不需目标写“无目标选择”并指明结果接受者。 | [对象与范围](dictionary/targets.md) | 不默认全场、最近目标或包括自身。 | 战场上的己方受伤随从；包括来源。 |
| 选择规格 | 需要选择时必填：选择者、数量、方式、是否可放弃；模式、方向、分配同样属于选择。 | [选择字典](dictionary/selection.md) | 不把“一个目标”当作已说明由谁选择。 | 发动者选择恰好 1 个，不可放弃目标而继续发动。 |
| 执行内容 | 必填。明确操作、对象、数值及多步依赖。 | [结果字典](dictionary/results.md) | 没有通用的缺省收益。 | 对所选随从治疗 1 点。 |
| 使用上限与统计对象 | 必填，但可引用既定默认；声明例外时写完整。 | [次数字典](dictionary/usage.md) | 引用 4.5：每张牌的每项主动能力默认每回合一次，随从与法术相同。 | 按 4.5 默认。 |
| 计次与刷新依据 | 必填，可引用通用条款。区分每回合上限与哪次尝试消耗次数。 | [4.5.1](../actions.md#发动步骤)、[3.2](../rounds.md#回合开始) | 计次口径尚待审阅，不能因为上限已确认便将整套口径当作已定。 | 依 4.5.1 的审阅结果；按回合刷新。 |

### 7.2.1.1 条件必填的补充项

| 出现何种设计 | 必须补什么 | 入口 |
| --- | --- | --- |
| 发动后留下加成、状态或另一项能力 | 承载者、具体作用、期限、对来源的依赖；赋予能力时链接其完整规格。 | [持续效果](continuous.md)、[期限字典](dictionary/duration.md) |
| 安排将来的结算 | 哪位玩家的哪个阶段、开始或结束、当前或下一次；对象跟随卡牌还是格子。 | [期限字典](dictionary/duration.md) |
| 多项成本或改变局面的成本 | 各项支付内容、可支付条件；通用时序不足的交互列为待裁定。 | [8.3 成本支付](../effects.md#成本支付) |
| 允许例外、分支或多步结果 | 明确改变哪条限制、各分支条件、后一步是否依赖前一步成功。 | [8.7 失败与部分完成](../effects.md#取消失败与部分完成) |
| 采用其他统计期间或共享次数 | 谁共享、何时消费与恢复；不得只写“限一次”。 | [次数字典](dictionary/usage.md) |

来源失效、目标离场、支付与反制的顺序由[第八章](../effects.md)及 4.5.1 裁定。完整设计稿应链接相关问题，不能通过自行填写一个“默认顺序”绕过尚未完成的通用规则。

## 7.2.2 可复制填写模板

```text
效果名称：
工作方式：主动
来源与发动者：
来源可用区域：
额外发动条件：无／逐项说明
操作窗口：引用 4.5
发动成本：无／支付者、内容、数量
目标范围：区域、类型、控制关系、空间范围、是否包括自身
选择：选择者、方式、数量、是否允许放弃；无选择则写明
执行内容：对象、操作、数值、步骤与依赖
使用次数：引用 4.5 默认／完整例外
计次与刷新：引用条款；未定交互列入审阅
留下的持续作用：无／链接完整作用与期限
延迟执行：无／指定时点与对象定位
其他例外：无／说明仅改写的部分
依赖的未决裁定：无／具体问题与链接
卡面文案：
```

## 7.2.3 完整示例：战地修复

**教学设计示例，不新增正式卡牌。** 假设一张随从具有以下能力，示例只设计能力，不替这张随从决定购买价格或基础属性。

| 要素 | 本例填写 |
| --- | --- |
| 工作方式、来源、发动者 | 主动；具有该能力的随从；其控制者发动。 |
| 区域与有效条件 | 来源在战场、能力有效；无额外发动条件。 |
| 窗口与成本 | 引用 4.5 的己方时动阶段；无额外发动成本。 |
| 候选对象 | 战场上当前生命低于生命上限的己方随从，不限距离，包括来源。 |
| 选择 | 发动者从候选中选择恰好 1 张，不重复；没有候选时不能发动。 |
| 执行内容 | 对所选随从治疗 1 点，治疗依 6.1.3。只有一个结果步骤。 |
| 次数、统计对象与刷新 | 引用 4.5：该牌的这项主动能力每回合一次；刷新引用 3.2。 |
| 计次口径 | 引用 4.5.1；被反制等边界仍随该通用条款审阅。 |
| 持续、延迟与例外 | 均无。不赋予状态，不安排未来事项，不改变普通行动权限。 |
| 未决依赖 | 发动后目标失效等通用失败情形引用 8.7；不为本例另立默认。 |

**卡面文案：**「主动：选择战场上的一个己方受伤随从，使其恢复 1 点生命。」主动的窗口与每回合一次引用通用规则，不必在每张卡面重复。

一次没有反制、控制权或目标变化的示例结算：己方时动中，来源能力有效且本回合尚未使用，玩家选择当前生命 2／上限 4 的己方随从；成功发动后，该随从变为 3／4，本项能力本回合的可用次数用尽。这段示例不决定发生反制时是否计次。

## 7.2.4 含糊写法与修正

**含糊：**「主动：治疗一个单位。」它没有说明谁能成为目标、选取范围和治疗量，也无法判断能否治疗满生命单位。

**修正：** 使用上例的候选范围、选择规格和数值。若实际意图是“只能治疗距离 2 以内的其他友方随从”，须在目标范围与卡面同时写明中心、距离和排除自身；不能仅凭插画或效果名称增加限制。

## 7.2.5 交付前检查

- 发动者、来源区域与操作窗口是否明确？是否误把时停触发当作时停主动能力？
- 没有合法必需目标或付不起完整成本时，能否明确判定不能发动？
- 每一步究竟是成本还是结果，次数上限与计次事实是否区分？
- 持续、延迟、失败与来源变化是否链接相应规则，没有补造通用裁定？
