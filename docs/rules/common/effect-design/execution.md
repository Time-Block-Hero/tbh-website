主动能力与触发效果的主体，需要描述一段可逐步执行的内容：选择对象，取得后续需要的数值，然后对指定对象进行操作。伤害、抽牌、弃牌、召唤等是这些步骤的结果，**不是与主动能力、持续效果并列的新效果种类**。

## 7.5.1 选择与执行

| 部分 | 设计稿需要写什么 | 例子 |
| --- | --- | --- |
| 选择 | 选择什么、合法候选、数量、方式，以及后续哪一步使用结果。 | 选择一个方向；指定一个格子；从手牌选择一张牌。 |
| 执行 | 对象、操作、数值及具体参数。对象可来自此前选择，也可直接指定自身或事件对象。 | 对所选方向的第一个合法目标造成伤害；给自己增加护甲。 |
| 计算与记录 | 如何从既有选择或局面得出数值，取值时点，以及后续用途。 | 记录作为成本弃置的卡牌费用，供主体计算护甲。 |
| 分支与逐项处理 | 何种条件走哪一条分支；对哪些对象分别做什么；数量是否固定。 | 格子上有随从时造成伤害，有法术时执行另一操作。 |
| 失败依赖 | 哪一步必须成功后才能继续，哪些步骤互相独立。 | 无合法对象时不能完成必需选择；后续独立抽牌是否继续须有依据。 |

候选范围见[对象字典](dictionary/targets.md)，玩家选择、随机、全体等方式见[选择字典](dictionary/selection.md)，具体操作见[结果字典](dictionary/results.md)。未决失败情况引用[8.7](../effects.md#取消失败与部分完成)，不能默认全部回滚或默认全部跳过。

卡文以“然后”连接的步骤具有成功依赖；没有“然后”且没有其他依赖条件的效果彼此独立。设计与失效结果统一按[8.7.1](../effects.md#不同失败阶段)描述，不把“然后”仅当作普通连接词。

## 7.5.2 准备、成本与主体的分工

一项主动能力可在发动前准备目标，再支付成本，成功发动后执行主体。若费用取决于选中的对象或位置，需要在费用确定前完成相关选择；若主体才需选择对象，应清楚写在主体对应步骤中。

「黑市护甲贩」需要把“弃置一张手牌”归为成本，把“令友方随从获得护甲”归为主体。弃牌费用是两部分之间传递的数值；已确认使用弃牌前的费用记录，见[7.2.4](activated.md#有选择和成本的实牌)。

图 7-B 只表示描述上的依赖，**不规定反制、触发和检查点插入的位置**；完整行动时序由[第八章](../effects.md)统一定义。

```mermaid
flowchart LR
    P[准备中确定需要的选择] --> C[成本使用这些选择完成支付]
    C --> B[主体使用已确定的对象与数值]
    B --> S[主体内继续选择或计算]
    S --> A[执行对应操作]
```

有的能力没有准备选择或成本，可以省略相应部分。某一步完成后的其他触发是否在下一步之前处理，不由图中连线决定。

## 7.5.3 实牌示例：预判投弹

「预判投弹」先指定一个格子，然后在慢速对应的时点查看该格子：若有随从，造成 4 点伤害；若有法术，将其移入弃牌堆。

设计上需要分别记录：

1. **选择的是格子。** 后续查看这个位置，并不自动跟踪选择时站在其中的卡牌。
2. **执行时间延后。** 必须引用“慢速”的明确时点，不能只写“以后”。
3. **按届时条件分支。** 随从与法术对应不同操作，资源牌不能被默认为其中一种。
4. **操作词有自己的定义。** 时停产生的慢速时点见[慢速词条](../../reference/keywords.md#慢速)；预判投弹已将含糊的“摧毁”改为“移入弃牌堆”，不产生随从死亡，也不是移除到虚空。

这个例子保留真实卡牌的待定问题。结构写全能让缺口可见，并不表示所有步骤已经有唯一结算答案。

## 7.5.4 赋予作用与安排延迟

一次执行可以给对象增加数值，也可以赋予一份[持续效果](continuous.md)。前者要明确对象和数值；后者必须连同承载者、期限、条件、范围及作用内容一并定义，不能只写“获得光环”。

已经建立的延迟事项不因来源随后死亡或离场自动取消；刺客-J 的已建立消灭效果采用这项规则，主定义见[8.6](../effects.md#持续时间与失效)。若设计要求来源届时仍在场，应明确写出条件。

安排将来的执行，还要写明是哪名玩家的哪个阶段、开始还是结束、当前还是下一次，以及后续跟随卡牌还是固定格子。期限选项见[7.6 期限字典](dictionary/duration.md)。普通移动、瞬移和冲撞引用[4.3](../actions.md#移动与特殊位移)；跨区域移动引用[6.5](../lifecycle.md#区域转移与状态保留)，不能通过执行步骤恢复已取消的击杀推进等规则。

## 7.5.5 可复制填写模板

```text
这段内容属于：主动准备／成本／主动主体／触发主体
输入：先前确定的对象、格子、数值或事件信息；没有则写无
步骤一：选择／计算／执行，写明对象与全部参数
步骤二：如何使用上一步的结果
分支或逐项处理：如有，写条件、对象集合和各分支内容
延迟或赋予：如有，链接完整时点或持续效果定义
失败依赖：引用通用规则，并列出尚未有裁定的具体情况
```
