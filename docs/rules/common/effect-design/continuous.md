持续效果描述在条件成立期间**持续提供的作用**，不是重复执行的一串触发。其与一次性修正的区别统一见[6.2.3](../lifecycle.md#持续加成与一次性修正)。设计时要分别回答效果是否还存在、此刻是否生效、目前影响谁。

## 7.4.1 必填要素

| 要素 | 含义与必填条件 | 选项或定义入口 | 省略时的处理 | 填写例 |
| --- | --- | --- | --- | --- |
| 来源 | 必填。谁提供本项持续作用，来自卡面还是另一项效果的赋予。 | [对象字典](dictionary/targets.md) | 不能只写“全体 +1”而没有来源。 | 战场上的这张随从。 |
| 承载者 | 必填。效果本身附着在哪里；可与最终受益者不同。 | [对象字典](dictionary/targets.md) | 不默认被影响对象各自永久获得一份。 | 光环由来源随从承载，周围随从只是受益者。 |
| 存在期限 | 必填。何时开始存在，何时终止；不能只给一个状态条件。 | [期限字典](dictionary/duration.md) | 不默认永久，也不默认回合末清除。 | 来源在战场期间提供此项持续作用。 |
| 生效条件 | 必填。存在期间还须满足什么条件；无额外条件写“无”。 | [条件字典](dictionary/conditions.md) | 不把条件暂时不成立误写为永久删除效果。 | 来源位于其控制者的领土内。 |
| 受影响对象与范围 | 必填。区域、类型、控制关系、范围中心、距离、是否包含自身。 | [对象与范围](dictionary/targets.md) | “附近”“队友”不是完整范围。 | 战场上距来源 1 以内的其他己方随从。 |
| 提供的作用 | 必填。明确提供属性修正、许可／限制，或赋予另一项完整效果。 | [结果字典](dictionary/results.md) | 不用“强化”“失能”等未定义词代替规则。 | 攻击力增加 1。 |
| 作用参数 | 必填。写清操作和数值；非数值作用写清被改变的权限及边界。 | [结果字典](dictionary/results.md) | 增加 1、设为 1、乘以 1 含义不同。 | 对当前受益者提供一份攻击力 +1 的持续贡献。 |
| 来源依赖与对象变化 | 必填，可引用持续贡献规则；说明是跟随当前范围还是一次锁定的一组对象。 | [6.2.3](../lifecycle.md#持续加成与一次性修正) | 不默认离开范围后仍保留加成。 | 随来源当前位置判断当前范围；作用依赖此光环继续生效。 |

### 7.4.1.1 按作用补充的内容

| 作用 | 必须补充 | 不能含糊之处 |
| --- | --- | --- |
| 修改属性或费用 | 具体属性、加减／设置等操作、数值来源。涉及多项修改的组合引用统一规则。 | 最大生命与当前生命是不同内容；不能笼统写“生命 +1”后任意结算。 |
| 赋予权限或施加限制 | 谁、什么行动、在哪个阶段或条件下受到哪一项改变。 | “无法行动”不能自动涵盖移动、攻击、主动、触发与持续全部类别。 |
| 赋予另一项效果 | 给谁、赋予哪份完整效果、有效区域及生效期限；该效果依其类别另填模板。 | “获得主动能力”没有正文；“获得某触发”没有事件，都不完整。 |
| 需要选择承载者或范围中心 | 选择发生在哪里、谁选、候选与数量，以及跟随对象还是固定格子。 | 若由一项主动／触发效果创建，应在创建它的效果中填写选择，不能让光环反复要求选目标。 |
| 持续作用受某个额度制约 | 额度归属、消耗事件和恢复时点；确认这是否实际是有限次的替换或触发效果。 | 持续效果没有统一“每回合发动一次”默认。 |

两个来源的同名光环怎样组合、赋予的同名能力是否各有次数，以及反复进入范围是否恢复已用次数，须引用对应裁定；没有裁定时记录问题，不允许设计稿留空并假定叠加。

## 7.4.2 存在、生效与贡献

以“战场上的随从在己方领土内提供光环”为例：

- **存在期限**限定这份战场光环在哪段期间可用。
- **生效条件**决定处于该期间时，光环是否正提供作用。
- **范围与贡献**决定此刻谁得到什么。

走出指定领土可以停止贡献，重新进入可以再次满足条件；这不表示每次进入都永久添加一份攻击加成。来源离场、目标离开范围等变化，依[持续贡献](../lifecycle.md#持续加成与一次性修正)与[8.6](../effects.md#持续时间与失效)处理。具体检查插入在哪个结算点由第八章决定，不由每个光环另行决定。

## 7.4.3 可复制填写模板

```text
效果名称：
工作方式：持续
来源：
承载者：
存在期限：起点、终点；引用区域或明确时点
生效条件：无额外条件／逐项说明
受影响对象：区域、类型、控制关系
空间范围：中心、形状或距离、是否包含自身
提供的作用：修改／许可或限制／赋予另一项效果
作用参数：具体属性、操作、数值；或完整权限；或效果规格链接
对象与范围变化：跟随当前范围／明确的锁定对象及依据
对来源的依赖：引用 6.2.3／明确例外
选择：无／在创建此持续作用的效果中定义并链接
次数限制：不适用／相关额度的完整定义与依据
多个来源及重入边界：引用已有裁定／列为待裁定
依赖的未决裁定：无／具体问题与链接
卡面文案：
```

## 7.4.4 完整示例：据点指挥

**教学设计示例，不新增正式卡牌。** 本例是一份依赖来源的属性光环。

| 要素 | 本例填写 |
| --- | --- |
| 来源与承载者 | 都是具有此效果的随从；其他随从只是当前受益者。 |
| 存在期限 | 来源在战场期间的持续作用；来源入场时仍须满足效果有效性要求。 |
| 生效条件 | 来源位于其控制者的领土内，且本项效果未被封锁。 |
| 受影响对象 | 战场上的其他己方随从，不包括来源。 |
| 空间范围 | 以来源当前格为中心，按 2.5 距离规则，距离不超过 1。 |
| 提供作用与参数 | 每个符合条件的受益者从本效果获得攻击力 +1 的持续贡献，不修改移动、生命或攻击范围。 |
| 对象变化与来源依赖 | 使用当前范围与控制关系；本例贡献只在来源条件与对象条件均成立时提供。 |
| 选择与次数 | 无玩家选择，无发动或使用次数。 |
| 多个来源 | 本例只演示一个来源；多来源叠加按通用裁定，尚未裁定则记录。 |
| 未决依赖 | 控制变化的具体结算、多份修改的组合、变化触发的检查点引用第六、八章。 |

**卡面文案：**「此随从位于己方领土内时，距离其 1 以内的其他己方随从攻击力 +1。」

假设场上只有这一项攻击修正，邻格的己方随从原攻击力为 2，则其攻击力为 3；它离开范围后，本光环不再贡献这 1 点，攻击力恢复为 2。攻击力修改的生效不等于该随从发起一次攻击。

### 7.4.4.1 如果要改成赋予能力

不能只将“攻击力 +1”替换为“获得主动效果”。应把作用改写成“范围内的受益者获得某项完整定义的主动能力”，再链接[主动效果模板](activated.md)填写那项能力的来源、使用者、区域、选择、成本、结果和次数。此时受益者成为被赋予能力的来源，而原随从仍是持续授予者。

还须明确离开范围后不再具有该能力，以及重新获得时怎样处理已经消耗的次数。后一问题没有通用裁定前，不能把反复进出范围写成自动刷新的办法。

## 7.4.5 含糊写法与修正

**含糊：**「友军获得强化。」它没有指出友军范围、强化内容、来源条件，也分不清是一次永久修改还是光环。

**修正：** 若意图是光环，按上例写出存在期限、生效条件、动态范围和贡献。如果意图是“入场时给选定随从一次 +1 攻击修正”，改用[触发效果](triggered.md)，并说明那份修正的期限；不要仅因结果维持一段时间就将整个入场效果分类为持续效果。

## 7.4.6 交付前检查

- 存在期限与生效条件是否分开？临时不满足条件与作用到期能否区分？
- 来源、承载者和受益者是否明确？范围是否包括自身？
- 每次条件变化是在更新当前贡献，还是明示创建一份新修正？
- 若赋予能力，是否真的附上该类能力的完整规格及限次边界？
