## 7.6.9 字典的使用边界

字典服务于[主动能力](activated.md)、[持续效果](continuous.md)、[六类作用](contributions.md)及[执行内容](execution.md)，不把它们重新划成四种平级模板。持续效果的受影响对象、触发所观察的事件对象、执行内容选取的目标，应分别填写。

**可描述不等于已批准。** 条目引用已确认的主规则，也保留具体待裁定边界；不能把新增事件、可选发动、新的支付方式或期限当成现成权限。系统的工程字段与旧运行数据中的玩法差异记录在维护附录，不直接成为玩家规则。

同时触发排序、连带死亡及嵌套伤害的插入点、窗口外可选放弃的随机分布，仍由[第八章](../effects.md)及其[审阅事项](../../maintenance/pending.md#第八章审阅事项)裁定。
