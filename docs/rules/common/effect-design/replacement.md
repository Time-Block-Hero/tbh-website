替换或阻止效果针对**尚未完成的变化**，改写其中明确指定的部分。它必须说清“原本要发生什么、把哪一部分改为什么”；事件完成后再产生收益，使用[触发效果](triggered.md)。前后边界与冲突处理归[8.4](../effects.md#结算前改写与结算后触发)。

## 7.5.1 必填要素

| 要素 | 含义与必填条件 | 选项或定义入口 | 省略时的处理 | 填写例 |
| --- | --- | --- | --- | --- |
| 来源与承载者 | 必填。指出谁提供规则、效果附着在哪个对象。 | [对象字典](dictionary/targets.md) | 不默认全场永久有效。 | 具有本效果的战场随从。 |
| 有效区域与存在期限 | 必填。何处、何时可参与改写。 | [期限字典](dictionary/duration.md) | 不默认离场后继续改写未来事件。 | 来源在战场且效果有效期间。 |
| 拟发生的事件 | 必填。指出尚未完成的具体变化，不能使用事后事实代替。 | [事件字典](dictionary/events.md) | “购买时”不足以区分支付、转区与购买成功。 | 一次购买即将把所购牌从商店移入弃牌堆。 |
| 适用对象与条件 | 必填。指定涉及谁、什么牌、哪些数值或原因。 | [对象](dictionary/targets.md)、[条件](dictionary/conditions.md) | 不默认自身、己方或全部事件。 | 购买者为来源控制者。 |
| 被改写的部分 | 必填。改写数值、目标、目的地、某一步，还是阻止整项变化。 | [结果字典](dictionary/results.md) | 改变目的地不意味着取消购买费用。 | 只改写这次购买转区的目的地。 |
| 替代结果 | 必填。明确新数值、新对象、新目的地或被阻止的内容。 | [结果字典](dictionary/results.md) | “取消效果”不能说明究竟哪项变化不发生。 | 目的地由该玩家的弃牌堆改为手牌。 |
| 选择与是否可拒绝 | 必填，无选择应写明；新增可选方式须有完整处理。 | [选择字典](dictionary/selection.md) | 不自动开放反应窗口或给予玩家临时拒绝权限。 | 满足条件必定应用，无玩家选择。 |
| 成本与使用限制 | 必填。无成本、无限次须明确；有限次须补统计对象和消费事件。 | [成本](dictionary/costs.md)、[次数](dictionary/usage.md) | 不套用主动能力的每回合一次。 | 无额外成本，无独立次数上限。 |
| 消耗与失效 | 有限次或抵挡后移除状态时必填；否则写“不适用”。 | [期限](dictionary/duration.md)、[次数](dictionary/usage.md) | 仅匹配候选、实际应用、成功阻止不是同一件事。 | 圣盾抵挡后移除圣盾，引用词条。 |
| 与其他改写的关系 | 必填，可引用通用裁定；没有裁定须列出具体冲突。 | [8.4](../effects.md#结算前改写与结算后触发) | 不默认后来获得、卡面位置或玩家选择者优先。 | 同一次购买有两个目的地改写时，等待统一排序裁定。 |

若替代结果还要求重新选择目标、转移到另一格或创建另一项变化，须填写对应的合法性与结果规格。不能只写“改为另一目标”，然后让系统随意寻找一个对象。

## 7.5.2 改写的边界

完整设计须能回答：原事件哪些内容改变，哪些继续按原行动规则执行。只改写目的地，不自动改价格、支付者或购买成功条件；阻止一次伤害，也不自动取消发起该伤害的整次攻击及其所有后续。

[圣盾](../../reference/keywords.md#圣盾)是已有阻止规则的例子：抵挡承载者下一次伤害，抵挡后消除该状态。其与护甲、多段伤害、零伤害的交互继续引用词条与第六章；不能为了补齐本页示例就把尚未确认的顺序定案。

**替换不是事后补偿。**“购买目的地改成手牌”没有中途进入弃牌堆的事实；“购买进弃牌堆后再拿到手牌”则是两次转区。它们引发的事件以及[区域修正继承](../lifecycle.md#区域转移与状态保留)分别按实际发生的变化判断。

## 7.5.3 可复制填写模板

```text
效果名称：
工作方式：替换／阻止
来源与承载者：
有效区域与存在期限：
拟发生事件：动作、主体、对象、发生前节点
适用条件：控制关系、区域、类型、数值或原因
改写范围：仅改变什么／阻止哪项完整变化
替代结果：新的数值、目标、目的地或不执行的变化
选择与拒绝：无选择且必定应用／完整选择规格及依据
额外成本：无／完整支付规格及适用依据
使用限制：无／上限、统计对象、期间
额度或状态消费：不适用／在何种事实发生后消耗什么
终止条件：期限结束／额度耗尽／状态移除／其他明示条件
相互冲突：引用通用规则；未定时记录具体碰撞案例
其他例外：无／明确改写的部分
依赖的未决裁定：无／具体问题与链接
卡面文案：
```

## 7.5.4 完整示例：前线补给

**教学设计提案，不新增正式卡牌，也不批准新的购买例外。** 本例用于展示如何把“改变购买目的地”写成完整效果规格；引入实际卡表前仍须审阅。

| 要素 | 本例填写 |
| --- | --- |
| 来源与承载者 | 同一张具有此效果的随从。 |
| 区域与期限 | 来源在战场且本项效果有效期间；不延续为来源离场后的规则。 |
| 拟发生事件 | 一次购买准备把所购牌从商店移入购买者的弃牌堆。 |
| 适用条件 | 购买者是来源控制者；对象为本次购买的那张牌，原目的地是该购买者的弃牌堆。 |
| 改写范围 | 只改本次购买转区的目的地。 |
| 替代结果 | 将目的地设为该购买者的手牌；不先放入弃牌堆。 |
| 选择与拒绝 | 无选择；满足条件则应用，不提供拒绝选项。 |
| 额外成本 | 无。购买本身的价格与支付继续按第五章。 |
| 次数、消费与终止 | 无独立使用上限，不消费次数或移除来源；离开规定有效期间后不再提供改写。 |
| 其他内容 | 不改变候选牌、购买价格、支付者或购买取消与成功的定义。 |
| 相互冲突与未决依赖 | 另有改写目的地的效果时，依 8.4 的统一裁定；该排序尚未完成。购买途中失败依第五、八章，不为本例补退款规则。 |

**卡面文案：**「此随从在战场期间，你购买的牌改为直接进入你的手牌，而非弃牌堆。」

在只存在这一项目的地改写、没有反制和来源变化的示例局面中，玩家合法购买一张牌并完成规定支付，该牌从商店直接进入手牌；不会先进入弃牌堆再返回。原本要求“进入弃牌堆”的触发条件不能仅因普通购买通常如此就视为发生。

本例完整填写的是一项效果的设计意图。它没有解决“另一个效果也要修改目的地时谁先应用”，因此遇到该交互前必须完成通用裁定；不能把完整模板误当作完整游戏时点模型。

## 7.5.5 含糊写法与修正

**含糊：**「购买后，牌进入手牌。」“后”意味着购买已经完成，但没有说明是改写购买目的地，还是购买完成后又做一次转区。

**修正：** 若意图是替换，使用上例“购买的牌改为直接进入手牌”的规格。若意图是额外回收，则改用触发效果，明确观察购买成功、随后将哪张牌从哪个区域移入手牌，并接受两次转区各自的结算结果。

## 7.5.6 交付前检查

- 被改写的变化是否尚未发生？是否误把治疗、退款或回收写成阻止已经发生的事实？
- 只改哪些部分，结果怎样变化，能否完整指出？
- 有选择、成本、状态消耗或限次时，是否合法且有对应的处理依据？
- 两个替换同时适用时，是否诚实链接未决裁定，没有自行赋予优先级？
