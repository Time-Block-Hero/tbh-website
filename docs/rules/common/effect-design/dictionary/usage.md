一项限制由“统计主体＋期间＋上限＋消耗事实＋恢复／继承规则”共同定义。主动能力引用[4.5](../../actions.md#主动能力)已确认的默认，不把它机械推广到触发、持续或替换。

## 7.6.8.1 上限与计数内容

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 限制发动或适用次数，也可筛选第几次事件。 |
| 必填与可选参数 | N 值；限制的是发动、完成还是事件出现；每项效果独立还是共享。 |
| 省略规则 | 触发和替换不可省略后直接套用主动每回合一次；设计稿写明不设本效果限次或具体上限。 |
| 填写示例 | 每回合本效果最多成功发动 2 次。 |
| 规则依据与边界 | 主动默认已确认；成功／被取消的计数口径仍须跟进[4.5.1](../../actions.md#发动步骤)。 |

## 7.6.8.2 统计主体

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 记录属于哪份效果、哪张牌、哪份被赋予效果或哪位玩家。 |
| 必填与可选参数 | 主体身份；多来源赋予相同效果时独立或共享；控制变化后的归属。 |
| 省略规则 | 同名卡不是同一计数主体；不默认随控制改变重置。 |
| 填写示例 | 每张牌各自拥有本项效果的次数记录。 |
| 规则依据与边界 | 玩家共享或授予实例的详细继承是待审阅设计，不由程序编号决定。 |

## 7.6.8.3 统计期间

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 限定整局、本回合、某个阶段、每次入场等期间。 |
| 必填与可选参数 | 期间种类；阶段的所属玩家；开始、结束及恢复节点。 |
| 省略规则 | 不把自己的时动开始当回合刷新；重入是否新额度须明确。 |
| 填写示例 | 每回合最多 1 次；刷新引用[3.2](../../rounds.md#回合开始)。 |
| 规则依据与边界 | 回合刷新已确认；每次入场、共享额度和里程碑等新窗口见 DES-R03。 |

## 7.6.8.4 消耗事实

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 明确哪一步真正占用一次额度。 |
| 必填与可选参数 | 尝试声明、成功发动、结果完成或明确事件之一；失败／取消的处理引用对应规则。 |
| 省略规则 | 不能把同一效果既在声明又在完成时各扣一次；未知口径不写成默认。 |
| 填写示例 | 计数引用主动能力成功发动口径，并将反制分支列为 A-07 待确认。 |
| 规则依据与边界 | [第八章](../../effects.md)；作者不以自己的计数选择绕开未定的通用反制规则。 |

## 7.6.8.5 恢复与跨区继承

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 说明额度在刷新、离场、重入、变形或换控制时如何延续。 |
| 必填与可选参数 | 采用已有生命周期规则；新例外需逐项写出变动及适用范围。 |
| 省略规则 | 清 modifier 不代表一切实例记录都已定义重置。 |
| 填写示例 | 回合开始刷新；本回合返回手牌再入场是否恢复次数，列待裁定。 |
| 规则依据与边界 | [6.5](../../lifecycle.md#区域转移与状态保留)、LIF-R08；必须区分设计未完成和已确认默认。 |
