**主动能力的使用额度与触发效果的历史次数条件分开填写。** 主动能力自带可用期间及发动上限，默认见[4.5](../../actions.md#主动能力)；触发可由外层持续效果的生效条件限制，例如“本项触发本回合成功发动少于 3 次”。持续和替换不自动继承主动的默认次数。

次数记录是卡牌进入游戏后维护的实例或事件记录，不是卡面基础属性。累计达标后触发的[进度效果](../triggered.md#进度效果)不同于限制发动次数，状态规则见[6.2.6](../../lifecycle.md#进度)。

## 7.6.8.1 次数记录的共同维度

| 词条 | 含义 | 需填参数 | 简例与边界 |
| --- | --- | --- | --- |
| **上限与计数内容** {#上限与计数内容} | 指定统计什么，以及何时达到限制。 | 上限；统计成功发动、事件发生还是其他明确事实。 | 主动每回合一次，支付时消耗，反制不返还；触发可用本项成功发动次数少于 3 作为生效条件。两者的组织位置不同，不能统一塞成一个额度字段。 |
| **统计主体** {#统计主体} | 指定哪份效果或哪张牌的记录。 | 效果实例或受影响对象；多来源是否各自独立。 | 同名两张牌不共享记录；“本效果发动次数”不同于“此随从移动次数”。共享设计需另行确认。 |
| **统计期间** {#统计期间} | 指定次数在哪段期间内累计。 | 本回合、整局或明确入场期间；必要时给出起止节点。 | 回合开始刷新已确认，见[3.2](../../rounds.md#回合开始)。每次入场或里程碑额度虽有实现用例，尚不能当作所有卡牌的默认规则。 |
| **消耗事实** {#消耗事实} | 明确何时占用额度或记入发生次数。 | 发生事实；失败、取消时是否计入依通用结算。 | 主动能力使用次数已消耗，不等于成功发动或主体执行成功；反制不返还，也不重复扣次，见[4.5.1](../../actions.md#发动步骤)。 |
| **进度完成** {#进度完成} | 按指定条件累计，达到目标才产生完成触发。 | 条件、增加量、目标、循环或一次性、有效区域与保留方式、完成效果。 | 累计本身不进连锁，循环保留余量；见[进度主定义](../../lifecycle.md#进度)。 |
| **保留回合数** {#保留回合数} | 记录该牌实际被保留的回合数。 | 读取当前值或明确的“视作”值；引用次数的收益公式或条件。 | 烈阳教会多张牌引用此状态，增加与转区清零规则统一见[6.2.7](../../lifecycle.md#被保留的回合数)。 |
| **恢复与跨区继承** {#恢复与跨区继承} | 说明重置、保留与新记录的边界。 | 回合刷新；离场重入、变形、归属变化的处理或例外。 | 按[状态保留类型](../../lifecycle.md#状态的转区保留类型)区分，清 modifier 不表示所有使用记录一并归零。未定继承见[6.5](../../lifecycle.md#区域转移与状态保留)及 LIF-R08。 |

> [!DETAILS] 主动额度、触发生效条件和普通行动额度
>
> 主动能力的使用额度只限制那项主动；触发外层的次数条件控制那份持续效果何时提供作用；移动行动点和普通攻击次数则属于行动规则。三者不能互相替代，也不能因为主动未写行动点成本，就额外扣一次移动。
