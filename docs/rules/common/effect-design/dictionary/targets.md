本页确定“哪些对象是候选”，选择多少及如何选择另见[7.6.3](selection.md)。范围是设计参数，不授予普通攻击、放置或移动新的权限。空间算法引用[2.5](../../elements.md#棋盘与空间关系)。

## 7.6.2.1 对象身份

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 玩家、卡牌实例、格子是三种不同对象。 |
| 必填与可选参数 | 必填对象种类与参照者；卡牌对象再填区域、基础类型及控制关系；可加职业、种族、收集属性筛选。 |
| 省略规则 | 不从“目标”推断为敌方随从，也不从同名推断为同一实例。 |
| 填写示例 | 你控制的、战场上的、非英雄随从。 |
| 规则依据与边界 | 控制关系见[2.1](../../elements.md#玩家与控制关系)；两者合并的提案及跨玩家转区边界正在审阅，不能沿用未确认的区分作为强制规则。 |

## 7.6.2.2 自身与事件对象

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 直接引用效果承载者、事件来源、事件受影响者、先前选择对象或死亡格。 |
| 必填与可选参数 | 引用对象的角色；若引用某次事件或前一步结果，明确是哪次／哪一步。 |
| 省略规则 | “它”有多个候选时不算完整设计。 |
| 填写示例 | 对刚刚受到伤害的那名随从回复 1 生命。 |
| 规则依据与边界 | 引用事件对象不等于再次选择；锁定与失效见[8.2](../../effects.md#目标模式与数量选择)。 |

## 7.6.2.3 指定区域内

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 从明确区域中按条件筛选。 |
| 必填与可选参数 | 区域属于谁；卡牌类型、控制／拥有关系；是否只含某个子集。 |
| 省略规则 | 不能默认“所有牌”只指战场；隐藏区可见性不自动改变。 |
| 填写示例 | 你的弃牌堆中的全部法术牌。 |
| 规则依据与边界 | 区域和可见性分别见[2.6](../../elements.md#游戏区域)、[2.7](../../elements.md#公开与隐藏信息)。 |

## 7.6.2.4 距离范围

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 以明确中心按既定距离计算候选格。 |
| 必填与可选参数 | 中心对象或格子、距离 N、是否包含中心；卡牌筛选另填。 |
| 省略规则 | 不将普通攻击默认范围套到效果范围。 |
| 填写示例 | 以此随从所在格为中心，四向距离 2 以内、不含自身的友方随从。 |
| 规则依据与边界 | 距离见[2.5](../../elements.md#棋盘与空间关系)；持续范围变化与一次选择冻结区别见[8.2](../../effects.md#目标模式与数量选择)。 |

## 7.6.2.5 矩形与方向范围

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 用形状、尺寸和朝向描述格子集合。 |
| 必填与可选参数 | 宽高、中心或起点、朝向；偶数尺寸定位和越界处理；如需线段另定义长度。 |
| 省略规则 | 没有默认中心、朝向或越界裁剪规则。 |
| 填写示例 | 以此格为中心的 3×3 范围；越界格不纳入（该裁剪方案须审阅）。 |
| 规则依据与边界 | 矩形是设计候选；缺失的空间约定列 DES-R03，不把示例裁剪升级为通则。 |

## 7.6.2.6 箭头与领土范围

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 依据有效箭头或某方领土筛选格子或卡牌。 |
| 必填与可选参数 | 使用谁的哪些箭头／哪位玩家的领土；选格还是格内牌；当前状态或事件前后。 |
| 省略规则 | “友方范围”不能替代明确箭头与领土定义。 |
| 填写示例 | 当前被此随从有效箭头指向的格子中的友方随从。 |
| 规则依据与边界 | 箭头见[2.5](../../elements.md#棋盘与空间关系)；领土内的持续条件与进入事件分别填写。 |
