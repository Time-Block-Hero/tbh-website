成本回答“为了发动先付出什么”。本页是设计所需参数，不批准所有支付方式。主动次数的使用限制见[7.6.8](usage.md)，不要同时把同一次使用重复扣作费用。支付次序与退款统一引用[8.3](../../effects.md#成本支付)。

## 7.6.5.1 无成本与星能成本

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 明确没有额外支付，或要求某玩家支付星能。 |
| 必填与可选参数 | 写“无”；或写支付者、星能数量／计算式及其修正来源。 |
| 省略规则 | 没有默认星能费，购买标价也不是主动或放置费。 |
| 填写示例 | 发动成本：此牌控制者支付 1 星能。 |
| 规则依据与边界 | 星能与购买标价见[5.1](../../economy.md#星能)；不以未来收益预付。 |

## 7.6.5.2 卡牌作为成本

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 以弃置、移除、献祭等明确动作支付卡牌。 |
| 必填与可选参数 | 动作名称、来源区域、卡牌条件、数量、选择方式及目的地；献祭去向必须说明。 |
| 省略规则 | 不能用“失去两张牌”代替具体动作；献祭没有通用默认目的地。 |
| 填写示例 | 献祭你控制的两名随从，将其移入你的弃牌堆（具体成本设计待审阅）。 |
| 规则依据与边界 | [6.3](../../lifecycle.md#死亡与消灭)明确献祭不是死亡；多项成本及触发结算见 T-04。 |

## 7.6.5.3 生命行动点与状态支付

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 提出以实例数值或状态支付的特殊成本。 |
| 必填与可选参数 | 支付对象、数值或状态、数量、是否允许致死、额度不足判断及用途。 |
| 省略规则 | 普通移动的行动点费用不自动适用于效果；不存在未写明的生命支付许可。 |
| 填写示例 | 移除此随从的圣盾作为发动成本（须审阅该支付规则）。 |
| 规则依据与边界 | 这些是条件必填的设计候选；可支付范围、事件语义与致死边界没有统一默认。 |

## 7.6.5.4 组合与替代成本

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 要求同时支付多项，或从若干完整方案选一。 |
| 必填与可选参数 | “全部支付”还是“择一”；每项完整参数；选择者；引用组合核验规则。 |
| 省略规则 | “支付 1 星能或弃 1 张牌”不能解释成两者都收；没有任选部分支付。 |
| 填写示例 | 选择支付 2 星能，或移除自己手牌中的 1 张指定类型牌。 |
| 规则依据与边界 | [8.3](../../effects.md#成本支付)；组合中的触发插入、不可完成后的处理须统一裁定。 |
