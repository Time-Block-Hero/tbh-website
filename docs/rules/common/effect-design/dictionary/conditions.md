条件描述为真假要求，不能在判断条件的同时悄悄支付费用或执行效果。必须说明条件用于来源可用性、事件过滤、目标筛选、生效条件还是结果分支；检查的具体时点引用相应结算规则。

## 7.6.4.1 区域与阶段条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 限制来源或目标所在区域，以及适用阶段。 |
| 必填与可选参数 | 对象、区域及所属玩家；阶段类型、哪个玩家的阶段；多条件之间的关系。 |
| 省略规则 | 不能只写“己方回合”而不说明本游戏的阶段。 |
| 填写示例 | 此牌在战场，且处于你的时动阶段。 |
| 规则依据与边界 | [第三章](../../rounds.md)、[操作窗口](../../actions.md#操作窗口)；条件不额外开放主动窗口。 |

## 7.6.4.2 关系与类别条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 根据控制关系、基础类型、职业、种族或收集属性判断。 |
| 必填与可选参数 | 参照玩家或对象；明确比较维度与值。 |
| 省略规则 | “非己方”不能自动改成“对手控制”；职业中立不表示无控制者。 |
| 填写示例 | 目标是对手控制的随从，且收集属性不是英雄卡。 |
| 规则依据与边界 | 分类见[第二章](../../elements.md)；拥有与控制的未决事项仍单独裁定。 |

## 7.6.4.3 数值与状态条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 检查某数值门槛或命名状态。 |
| 必填与可选参数 | 对象、数值原始／当前／上限、比较符及阈值；状态名称和层数（若已定义）。 |
| 省略规则 | 不把当前生命与生命上限混为一个值；状态叠加没有统一默认。 |
| 填写示例 | 此随从当前生命小于其当前生命上限。 |
| 规则依据与边界 | [2.4](../../elements.md#基础属性与对局状态)、[第六章](../../lifecycle.md)；新状态须定义获得、作用和结束。 |

## 7.6.4.4 领土条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 当前位置属于指定方领土，是持续条件。 |
| 必填与可选参数 | 参照玩家、领土关系、所检查的卡牌或格子。 |
| 省略规则 | 不代表刚刚发生进入事件。 |
| 填写示例 | 此随从位于你的领土内时，持续提供所述加成。 |
| 规则依据与边界 | 领土定义见[2.5](../../elements.md#棋盘与空间关系)；进入事件另见[事件字典](events.md#进入领土后)。 |

## 7.6.4.5 次数与历史条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 根据明确期间发生的事件计数。 |
| 必填与可选参数 | 统计事件、角色、主体、期间、比较方式、是否包含当前事件；引用限次规则。 |
| 省略规则 | “第一次”不可省略第一次什么、哪一段期间、属于谁。 |
| 填写示例 | 本回合此随从第一次完成拾取后……（本次是否计入由其触发条件明确）。 |
| 规则依据与边界 | [次数字典](usage.md)；新增历史统计及重入继承须审阅，不能只凭代码计数方式定案。 |

## 7.6.4.6 组合与分支条件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 全部成立、任一成立、否定；结果可按已定义条件分支。 |
| 必填与可选参数 | 分组关系；每个子条件；若用“否则”，明确对应哪项判断。 |
| 省略规则 | A 且 B 或 C 必须写括号含义，不能让读者自行猜。 |
| 填写示例 | 同时满足“在战场”和“当前生命不足上限”才可发动。 |
| 规则依据与边界 | 资格条件与效果正文分支不同；不能用执行后检查替代发动前限制。 |
