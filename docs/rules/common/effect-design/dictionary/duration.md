---
title: 7.6.7 执行时间与期限字典
id: card-effects/dictionary/duration
status: draft
---

执行时点、效果存在期限、生效条件是不同项目。即时结果没有必须填的持续时间；只有留下的修正、持续贡献或延迟事项需要对应字段。区域转移另按[6.5](../../lifecycle.md#区域转移与状态保留)判断，不把“本回合”理解为能跨逆向转区保留。

## 7.6.7.1 当前执行

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 到该效果的规定结算点处理结果。 |
| 必填与可选参数 | 执行步骤；若无延迟写“当前结算”。 |
| 省略规则 | 当前执行不等于刚发现触发便递归执行。 |
| 填写示例 | 轮到本效果时，获得 1 星能；不留下待执行事项。 |
| 规则依据与边界 | [8.5](../../effects.md#多个效果与连续结算)决定结算点。 |

## 7.6.7.2 本回合或指定阶段

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 修正持续到本回合或明确阶段的结束边界。 |
| 必填与可选参数 | 起点、终点；是哪位玩家的哪个阶段；当前还是下一次。 |
| 省略规则 | 不能只写“本阶段”而不明确其阶段实例；到期清理顺序不是单卡参数。 |
| 填写示例 | 所选随从本回合攻击 +2。 |
| 规则依据与边界 | [3.6](../../rounds.md#回合结束)、[8.6](../../effects.md#持续时间与失效)；阶段清理的未决细节继续审阅。 |

## 7.6.7.3 承载者存在或处于区域期间

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 以承载者存在或其所在区域作为存续边界。 |
| 必填与可选参数 | 承载者、区域、离开是否结束；若只暂停须与下一条区分。 |
| 省略规则 | 卡牌离开战场不等于实例从游戏中消失。 |
| 填写示例 | 此牌在战场期间存在一项持续效果。 |
| 规则依据与边界 | [6.2.3](../../lifecycle.md#持续加成与一次性修正)；重新入场是否重建记录另见生命周期。 |

## 7.6.7.4 有条件生效

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 效果尚存在，但只在条件为真时提供贡献。 |
| 必填与可选参数 | 存在期限另填；生效条件引用条件字典；不成立时停止的贡献。 |
| 省略规则 | 生效条件暂时不成立不自动表示定义被永久删除。 |
| 填写示例 | 效果在战场期间存在，仅当此随从在己方领土内时提供攻击加成。 |
| 规则依据与边界 | [持续模板](../continuous.md)；提供贡献的撤销由第六章处理。 |

## 7.6.7.5 指定未来时点

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 安排尚未执行的事项，未来到点执行。 |
| 必填与可选参数 | 哪位玩家、哪个阶段、开始／结束、当前／下一次；结果及对象引用规则。 |
| 省略规则 | “稍后”“慢速”没有可凭空补出的统一落点。 |
| 填写示例 | 安排在本回合购买阶段结束时获得 1 星能（示例落点需审阅）。 |
| 规则依据与边界 | [8.6](../../effects.md#持续时间与失效)；来源离场和对象锁定未定，需列为设计依赖。 |

## 7.6.7.6 直到使用或明示长期

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 以一次符合条件的使用结束，或提出长期存在的例外。 |
| 必填与可选参数 | 触发消耗的事实、承载者、可用区域；长期则须明示如何受转区和形态影响。 |
| 省略规则 | “永久”不自动覆盖逆向清除；“下一次”不等于无限等待且不受来源条件影响。 |
| 填写示例 | 下次成功购买时使用该费用修正；未成功时是否消耗按购买规则。 |
| 规则依据与边界 | [5.4](../../economy.md#购买卡牌)与[6.5](../../lifecycle.md#区域转移与状态保留)；长期新继承须单独批准。 |
