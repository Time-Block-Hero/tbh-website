每项选择先引用[对象与范围](targets.md)，再填本页参数。由谁选择、选择何时发生和失效处理依[8.2](../../effects.md#目标模式与数量选择)。不能把新选择方式当作额外操作窗口。

## 7.6.3.1 直接引用与全部

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 无需挑选：直接使用明确对象，或使用整个符合条件集合。 |
| 必填与可选参数 | 直接引用时填对象角色；全部时填范围及取样时点所引用的规则。 |
| 省略规则 | 不把“全部”变成玩家可以挑一部分；同时还是逐个变化须另填结果。 |
| 填写示例 | 此随从获得 1 护甲；或所有符合条件的友方随从各获得 1 护甲。 |
| 规则依据与边界 | 集合冻结及变化批次依第八章；尚未确定的统一时点不能由卡面随意指定。 |

## 7.6.3.2 玩家选择

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 由明确玩家从候选中挑选。 |
| 必填与可选参数 | 选择玩家、恰好 N／至多 N、最低数量、是否可重复；范围引用7.6.2。 |
| 省略规则 | 不默认可以放弃；省略选择者或数量不完整。 |
| 填写示例 | 由此牌控制者选择恰好 1 名其他友方随从。 |
| 规则依据与边界 | 窗口外方式引用[4.1.1](../../actions.md#操作窗口)，不重复设定；来源换控制后的锁定见 T-02。 |

## 7.6.3.3 随机选择

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 系统按规则从合法候选取样。 |
| 必填与可选参数 | 数量、不同对象还是允许重复、候选不足处理；概率分布引用已定规则或列待定。 |
| 省略规则 | 不自动把“随机”解释为所有组合等概率；不默认补足不存在的对象。 |
| 填写示例 | 随机选择 1 名符合条件的随从；无候选时跳过此独立步骤（失败方案待审阅）。 |
| 规则依据与边界 | 随机分布和部分完成见 T-05、ECO-R04；默认窗口外合法随机不等于这些细节已经确定。 |

## 7.6.3.4 模式方向与点数分配

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 选择可以是方案、四向之一，或把总量分配给目标。 |
| 必填与可选参数 | 列出所有模式；方向允许集；分配总量、各目标最少／最多、是否整数及可剩余。 |
| 省略规则 | 不自动允许拆分一个未写可分配的伤害值。 |
| 填写示例 | 选择上／下／左／右之一；冲撞距离及停止引用移动规则。 |
| 规则依据与边界 | [4.3.3](../../actions.md#冲撞移动)；多目标分配及窗口外随机分布仍见[8.2.2](../../effects.md#多目标与点数分配)。 |

## 7.6.3.5 无目标与中途失效

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 声明前缺少合法候选，和执行中目标失效是不同情形。 |
| 必填与可选参数 | 设计稿引用默认失败条款；有例外写明跳过、改选或依赖分支，并提交审阅。 |
| 省略规则 | 不能省略后默认为自动换一个有利目标或全部回滚。 |
| 填写示例 | “若以此消灭目标，则抽 1 张牌”明确要求前一步造成消灭。 |
| 规则依据与边界 | [8.2.3](../../effects.md#无合法选项与目标失效)、[8.7](../../effects.md#取消失败与部分完成)；未决失败方案不是作者自由选的通则。 |
