一次执行的结果与持续提供的贡献分别填写。每项结果写对象、数值／内容、步骤依赖；会留下修正或延迟事项时再链接[期限](duration.md)。这里不重新定义伤害、死亡或转区。

## 7.6.6.1 伤害治疗与护甲

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 执行一次伤害、治疗或护甲变化。 |
| 必填与可选参数 | 具体动作、来源／施加者、目标、数值；分段次数、同时对象及明示例外。 |
| 省略规则 | 造成伤害不等于消灭。 |
| 填写示例 | 对所选随从造成 2 点伤害；连续两次 1 点须另写为两段。 |
| 规则依据与边界 | [6.1](../../lifecycle.md#伤害护甲与治疗)；实际量、批次及零值触发仍以主规则的审阅状态为准。 |

## 7.6.6.2 属性修正

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 一次赋予 modifier，或持续提供属性贡献。 |
| 必填与可选参数 | 属性、加减／设定／倍率、值；一次性或持续；承载者、期限、可否叠加的规则引用。 |
| 省略规则 | 不把生命上限和当前生命写作同一个参数；不默认永久叠加光环。 |
| 填写示例 | 此随从在场期间，其他指定友方随从攻击 +1。 |
| 规则依据与边界 | [6.2](../../lifecycle.md#属性变化)、[6.5](../../lifecycle.md#区域转移与状态保留)；多种非交换修正顺序仍待定。 |

## 7.6.6.3 星能变化与费用贡献

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 使玩家获得星能，或提供某类费用的修正。 |
| 必填与可选参数 | 玩家、数量；改费用时填费用种类、适用交易、计算方式、期限或限次。 |
| 省略规则 | “购买减费”不降低全部星能支付；实际获星能与少付款不同。 |
| 填写示例 | 你的下一次成功购买减少 1 星能价格。 |
| 规则依据与边界 | [第五章](../../economy.md)；价格下限、取整和一次性消费按该章草案，不由本条另定。 |

## 7.6.6.4 抽牌弃牌与转区

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 抽取、弃置或把既有卡牌从指定区域移到另一处。 |
| 必填与可选参数 | 对象、数量、来源与目的区域及所属玩家；有序区域的顶／底／洗入；选择方式。 |
| 省略规则 | 进入手牌不自动算抽牌；进入弃牌堆不自动算死亡。 |
| 填写示例 | 将选中的随从从战场返回其指定接收玩家的手牌。 |
| 规则依据与边界 | [6.4](../../lifecycle.md#抽牌弃牌与洗牌)、[6.5](../../lifecycle.md#区域转移与状态保留)；控制改变后接收玩家需明确。 |

## 7.6.6.5 消灭与献祭

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 使用原因明确的离场动作。 |
| 必填与可选参数 | 动作、对象、数量；献祭须写去向；是否属于成本另列。 |
| 省略规则 | 不能把两种动作当成同义词。 |
| 填写示例 | 消灭所选非己方随从；或献祭两名己方随从并送往明示区域。 |
| 规则依据与边界 | 唯一判定与死亡时序见[6.3](../../lifecycle.md#死亡与消灭)。 |

## 7.6.6.6 移动与行动许可

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 改变位置，或持续允许某种移动／放置。 |
| 必填与可选参数 | 移动方式、对象、终点或方向距离；许可的主体、阶段、区域、占格及成本例外范围。 |
| 省略规则 | 额外许可不自动绕过所有合法性，也不恢复已取消的击杀推进。 |
| 填写示例 | 允许此随从瞬移到自己领土内的合法格，费用按瞬移规则。 |
| 规则依据与边界 | [4.2](../../actions.md#放置与箭头)、[4.3](../../actions.md#移动与特殊位移)；效果位移的额外特殊权限需单独定义。 |

## 7.6.6.7 生成召唤变形与复制

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 生成新实例、调来既有实例或改变原实例形态。 |
| 必填与可选参数 | 具体动作、卡牌定义、数量、归属、区域／格子；复制定义还是当前状态，变形继承项。 |
| 省略规则 | 不从“召唤”推定新生成；复制／变形没有统一全继承默认。 |
| 填写示例 | 在死亡格生成并召唤 1 个指定僵尸随从，由原效果指定玩家控制。 |
| 规则依据与边界 | [6.6](../../lifecycle.md#生成召唤升级与变形)；生成资源仍需空格，不能把召唤图标当占格例外。 |

## 7.6.6.8 添加或消除状态

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 对明确对象设置、增加或消除有定义的状态。 |
| 必填与可选参数 | 状态名、对象、数量／层数（如适用）、期限；状态已有时的处理。 |
| 省略规则 | 新状态不能只有名字没有规则，也不默认所有状态可叠层。 |
| 填写示例 | 为所选随从赋予圣盾；已有圣盾时的叠加处理须有对应定义。 |
| 规则依据与边界 | [关键词库](../../../reference/keywords.md)；状态的效果与消除条件由主条目维护。 |

## 7.6.6.9 赋予效果与规则限制

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 持续或一次性赋予完整效果，或限制某种行为。 |
| 必填与可选参数 | 获得者、被赋予效果的完整定义链接、期限；限制须指定动作及影响范围。 |
| 省略规则 | 不能只写“获得触发效果”而不写触发事件、对象和结果；不会自动赋予新操作窗口。 |
| 填写示例 | 此随从在场时，指定友方获得一项明确的“你的时动开始时获得星能”触发效果。 |
| 规则依据与边界 | 被赋予者按其[效果模板](../../card-effects.md)完整定义；来源与承载者、独立次数见7.6.8。 |

## 7.6.6.10 步骤组合与延迟

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 顺序、条件分支、指定次数重复、同批变化或延迟安排。 |
| 必填与可选参数 | 各步骤结果；依赖成功与否；重复上限；延迟落点；同步批次边界引用通用规则。 |
| 省略规则 | 不能写无限重复；“然后”不允许跳过死亡等必要检查。 |
| 填写示例 | 若以本效果消灭了目标，则抽 1 张牌。 |
| 规则依据与边界 | [8.5](../../effects.md#多个效果与连续结算)、[8.6](../../effects.md#持续时间与失效)；触发排序不是每张卡可填的优先级。 |
