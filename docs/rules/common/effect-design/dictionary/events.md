**DES-003 事件描述必须包含观察角色和发生前后。** 每个条目提供可填写的描述，适用于哪种玩法、何时成立以所引主规则为准。表中示例是教学设计，不是新增卡牌或新增事件的批准。匹配事件时读取哪些信息、后续何时执行由第八章规定。

## 7.6.1.1 进入战场后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 指定卡牌从其他区域进入战场。 |
| 必填与可选参数 | 观察自身／指定关系卡牌；需要时限定原区域、基础类型及进入原因。 |
| 省略规则 | 不可省略观察对象；不写原区域筛选表示不增加此筛选。 |
| 填写示例 | 入场：为此牌的控制者获得 1 星能。 |
| 规则依据与边界 | [入场](../../../reference/keywords.md#入场)已定义；不同进入方式与拾取的衔接见[8.5.3](../../effects.md#放置入场与拾取的衔接)。 |

## 7.6.1.2 被抽到后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 卡牌因抽牌进入手牌。 |
| 必填与可选参数 | 被抽的牌是自身还是其他牌；若观察其他牌，写明哪名玩家的抽牌及筛选。 |
| 省略规则 | 生成到手牌不默认为抽牌。 |
| 填写示例 | 此牌被抽到后，你获得 1 星能。 |
| 规则依据与边界 | [6.4.1](../../lifecycle.md#抽牌与空牌堆)；回合开始整批抽牌及窗口见第三章。 |

## 7.6.1.3 生成后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 新的卡牌实例被产生。 |
| 必填与可选参数 | 哪种卡牌、哪名玩家相关、生成到哪个区域；观察自身或其他实例。 |
| 省略规则 | 既有牌转区、变形不自动算新生成。 |
| 填写示例 | 你生成一张资源牌到战场后，获得 1 星能。 |
| 规则依据与边界 | [6.6.1](../../lifecycle.md#生成与召唤)；生成与入场各自触发的排序待第八章裁定。 |

## 7.6.1.4 进入弃牌堆后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 卡牌实际进入弃牌堆。 |
| 必填与可选参数 | 观察对象、接收玩家；是否限定为从手牌弃置、死亡或法术清理。 |
| 省略规则 | 不写原因限制时，不擅自只匹配死亡。 |
| 填写示例 | 此牌从手牌被弃置到你的弃牌堆后，获得 1 星能。 |
| 规则依据与边界 | [6.3.2](../../lifecycle.md#不同离场原因)区分原因；哪些事件可被同一效果合并观察需明示。 |

## 7.6.1.5 被移除后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 卡牌从其他区域进入虚空。 |
| 必填与可选参数 | 观察对象；可限定原区域和移除原因。 |
| 省略规则 | 资源被拾取后消失不满足移除。 |
| 填写示例 | 此牌从手牌被移除后，你抽 1 张牌。 |
| 规则依据与边界 | [移除](../../../reference/keywords.md#移除)；离场后效果资格依[8.7.2](../../effects.md#来源离场封锁与控制权变化)，未完整裁定。 |

## 7.6.1.6 指定区域迁移后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 观察一次明确的来源区域到目的区域迁移。 |
| 必填与可选参数 | 原区域、目的区域、被移动卡牌、玩家关系；需要时限定原因。 |
| 省略规则 | 不得只写“转移时”而不说明观察哪种迁移。 |
| 填写示例 | 己方牌从虚空进入商店后，获得 1 星能。 |
| 规则依据与边界 | [区域](../../elements.md#游戏区域)与[6.5](../../lifecycle.md#区域转移与状态保留)；条目不授予迁移许可。 |

## 7.6.1.7 形态改变后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 既有实例改变形态或定义。 |
| 必填与可选参数 | 观察对象；需要时限定变化前后形态。 |
| 省略规则 | 换形不自动算生成或入场。 |
| 填写示例 | 此牌变成指定形态后，获得 2 护甲。 |
| 规则依据与边界 | [6.6.2](../../lifecycle.md#升级变形与复制)；变形继承仍需裁定。 |

## 7.6.1.8 拾取时

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 一次资源拾取中观察拾取者或资源牌。 |
| 必填与可选参数 | 明确观察拾取者／被拾资源；资源筛选、收益玩家、发生在完成流程的哪一点。 |
| 省略规则 | 不能把“拾取者”和“资源拥有者”当作同一主体。 |
| 填写示例 | 当你完成拾取指定资源后，额外获得 1 星能。 |
| 规则依据与边界 | [拾取词条](../../../reference/keywords.md#拾取)和[6.8](../../lifecycle.md#拾取)；额外触发的精确点仍待定。 |

## 7.6.1.9 移动到格子后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 位置发生实际变化。 |
| 必填与可选参数 | 移动者、需要限定的移动方式、目的格条件；观察每步还是整次完成。 |
| 省略规则 | 不能把逐格进入与一次整段移动结束混用。 |
| 填写示例 | 此随从每次普通移动进入一个格子后，获得 1 护甲。 |
| 规则依据与边界 | [4.3](../../actions.md#移动与特殊位移)；逐格触发与继续行走的结算点由第八章定。 |

## 7.6.1.10 进入领土后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 本条描述因移动从指定领土外进入其中的事件。 |
| 必填与可选参数 | 哪位玩家的领土、移动者、原格在外且新格在内。 |
| 省略规则 | “位于领土内”不是“进入领土”。 |
| 填写示例 | 此随从因移动进入你的领土后，获得 1 护甲。 |
| 规则依据与边界 | [2.5](../../elements.md#棋盘与空间关系)；当前位置条件见[条件字典](conditions.md#领土条件)；放置或召唤到领土中是否属于另一种进入事件，尚待裁定，不能省略移动限定。 |

## 7.6.1.11 攻击事件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 区分攻击声明、被取消、结算完成三个事件。 |
| 必填与可选参数 | 必须选其中一个事件；观察攻击者／受击者；卡牌关系和附加条件。 |
| 省略规则 | 攻击完成不自动表示造成生命伤害；取消不等于 0 点伤害。 |
| 填写示例 | 此随从完成攻击后，你获得 1 星能。 |
| 规则依据与边界 | [4.4](../../actions.md#攻击与反击)；声明、取消、完成的细则仍随行动与第八章审阅。 |

## 7.6.1.12 造成或受到伤害后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 区分伤害来源造成伤害和受击者受到伤害。 |
| 必填与可选参数 | 观察来源／受击者；数值门槛、伤害原因或关系筛选；是否使用伤害量。 |
| 省略规则 | 不得仅写“伤害时”；溢出伤害量尚无默认。 |
| 填写示例 | 此随从受到实际伤害后，你获得 1 星能。 |
| 规则依据与边界 | [6.1.2](../../lifecycle.md#伤害事实与多段伤害)仍有草案细节；致死与触发先后不能靠本条决定。 |

## 7.6.1.13 伤害被抵挡后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 观察防护使伤害被抵挡的结果。 |
| 必填与可选参数 | 部分或全部抵挡、对象、防护来源筛选；若按抵挡量计算须写公式。 |
| 省略规则 | 不可省略部分／全部的区别。 |
| 填写示例 | 此随从的一次伤害被圣盾全部抵挡后，你获得 1 星能。 |
| 规则依据与边界 | [6.1](../../lifecycle.md#伤害护甲与治疗)；具体触发资格随该章审阅。 |

## 7.6.1.14 实际治疗后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 生命因治疗实际回复。 |
| 必填与可选参数 | 治疗者／被治疗者、数量门槛；是否读取实际回复量。 |
| 省略规则 | 治疗标称量不自动等于实际回复量。 |
| 填写示例 | 此随从实际恢复生命后，你获得 1 星能。 |
| 规则依据与边界 | [6.1.3](../../lifecycle.md#护甲与治疗)；零回复触发口径仍为草案。 |

## 7.6.1.15 死亡与击杀

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 死亡观察死者；击杀观察导致死亡的来源。 |
| 必填与可选参数 | 选择死亡或击杀；相关对象、原因筛选；需要的死亡格或其他离场前信息。 |
| 省略规则 | 死亡不等于任何离场；击杀归属不由最后操作的玩家推断。 |
| 填写示例 | 此随从死亡时，在其死亡格召唤一个指定僵尸。 |
| 规则依据与边界 | [6.3](../../lifecycle.md#死亡与消灭)已确认先清本体；其他离场前数值及击杀归属边界仍待定。 |

## 7.6.1.16 阶段开始或结束

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 观察一段明确阶段的起止。 |
| 必填与可选参数 | 时停／某玩家时动／购买／回合结束；开始或结束；属于哪名玩家或整个同步阶段。 |
| 省略规则 | 不可省略开始／结束或把“你的时动”写成未限定的“时动”。 |
| 填写示例 | 你的时动阶段开始时，你获得 1 星能。 |
| 规则依据与边界 | [第三章](../../rounds.md)；新起始效果优先时停开始，窗口引用[4.1.1](../../actions.md#操作窗口)。 |

## 7.6.1.17 购买事件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 区分声明、成功和取消。 |
| 必填与可选参数 | 选择事件、购买者、购买牌筛选；需要时限定实际价格或目的区域。 |
| 省略规则 | 成功购买不自动表示进入手牌。 |
| 填写示例 | 你成功购买一张随从牌后，获得 1 星能。 |
| 规则依据与边界 | [5.4](../../economy.md#购买卡牌)；价格锁定、取消和支付后续仍按该章草案。 |

## 7.6.1.18 星能变化后

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 区分获得、支付或其他明确调整。 |
| 必填与可选参数 | 哪名玩家、变化方向与原因、数值条件；读变化前／后值或变化量。 |
| 省略规则 | 余额减少不自动算支付，增加也不能替代原因筛选。 |
| 填写示例 | 你支付至少 2 星能购买卡牌后，获得 1 护甲的效果作用于指定随从。 |
| 规则依据与边界 | [5.1](../../economy.md#星能)；支付触发的结算点见第八章。 |

## 7.6.1.19 效果发动或状态变化

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 观察指定效果的成功发动，或状态的获得／失去。 |
| 必填与可选参数 | 精确选事件、来源或状态名、主体；状态叠加是否算再次获得。 |
| 省略规则 | 发动成功不等于执行完成；状态叠加不默认算新获得。 |
| 填写示例 | 此随从失去圣盾后，你获得 1 星能。 |
| 规则依据与边界 | [8.1](../../effects.md#通用结算边界与行动时序)；具体新事件和叠加语义需裁定。 |

## 7.6.1.20 拟发生的事件

| 项目 | 设计说明 |
| --- | --- |
| 含义 | 在发生前供替换或阻止匹配的事件。 |
| 必填与可选参数 | 事件种类（伤害、转区、购买等）、拟定对象与参数、拟改写部分。 |
| 省略规则 | 不因列入字典就开放新响应窗口，也不自动开放每种事件的改写。 |
| 填写示例 | 你购买的牌即将进入弃牌堆时，将这次目的地改为手牌。 |
| 规则依据与边界 | 用于[替换模板](../replacement.md)，不是事后触发；开放节点及冲突处理见[8.4](../../effects.md#结算前改写与结算后触发)。 |
