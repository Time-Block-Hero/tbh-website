**DES-003 事件描述必须包含观察角色和发生前后。** [触发效果](../triggered.md)既可以观察已经发生的事实，也可以在规则允许的发生前节点发动；不能把“发生前”全部归为结算替换。下表按游戏含义归并查找项；具体时点仍引用主规则，并非开放任意新响应窗口。

表中给出的是事件描述及必要筛选。效果监听哪名对象、向谁提供触发、执行时选谁，是三个不同问题，见[对象与范围](targets.md)。

## 7.6.1.1 发生后的事实

| 词条 | 含义 | 需填参数 | 简例与边界 |
| --- | --- | --- | --- |
| **进入战场后** {#进入战场后} | 卡牌从其他区域进入战场。 | 观察自身或其他卡牌；需要时限定原区域、类型、进入原因。 | 例如星能石的入场收益。建造中卡牌自身入场触发移至完成建造，其他牌仍观察真实跨区事件，见[4.2.3](../../actions.md#建造)。入场的定义见[关键词](../../../reference/keywords.md#入场)，不缩窄为仅从手牌放置；放置先入场后拾取见[4.2.2](../../actions.md#放置与拾取)。 |
| **被抽到后** {#被抽到后} | 卡牌因抽牌进入手牌。 | 被抽卡牌、抽牌玩家、卡牌筛选。 | 生成到手牌不自动算抽牌；[抽牌规则](../../lifecycle.md#抽牌与空牌堆)决定何时完成。 |
| **生成后** {#生成后} | 一张此前不存在的卡牌实例被产生。 | 新卡牌、相关玩家、最终区域。 | 既有牌转区或变形不算新生成；[生成与召唤](../../lifecycle.md#生成与召唤)有区别。 |
| **进入弃牌堆后** {#进入弃牌堆后} | 卡牌实际进入弃牌堆。 | 卡牌、接收玩家；需要时限定原区域和原因。 | 可筛选手牌弃置、死亡或法术清理；目的地相同不表示[离场原因](../../lifecycle.md#不同离场原因)相同。 |
| **被移除后** {#被移除后} | 卡牌进入虚空。 | 卡牌；需要时限定原区域、原因。 | 资源拾取后直接消失不属于[移除](../../../reference/keywords.md#移除)。 |
| **指定区域迁移后** {#指定区域迁移后} | 既有卡牌完成指定迁移。 | 卡牌、原区域、目的区域、相关玩家；需要时限定原因。 | 额外卡组与商店是不同区域。本条只描述事件，不授予新迁移许可；见[游戏区域](../../elements.md#游戏区域)。 |
| **形态改变后** {#形态改变后} | 既有实例改变形态。 | 观察对象；需要时限定变化前后形态。 | 变形不自动算生成或入场；继承项见[6.6.2](../../lifecycle.md#升级变形与复制)。 |
| **拾取时** {#拾取时} | 观察资源被拾取及其拾取者。 | 观察拾取者还是资源牌；资源筛选、收益玩家。 | 资源自己的拾取效果与“完成拾取后”的额外效果要区分；额外触发的精确点见[6.8](../../lifecycle.md#拾取)。 |
| **移动到格子后** {#移动到格子后} | 卡牌位置实际变化。 | 移动者、移动方式、目的格条件；逐步还是整段移动。 | 不要将每步进入与整次移动完成混写；见[移动](../../actions.md#移动与特殊位移)。 |
| **进入领土后** {#进入领土后} | 因移动从指定领土外进入其中。 | 领土所属玩家、移动者、原格与新格的关系。 | “位于领土内”是[持续条件](conditions.md#领土条件)；放置或召唤使用“进入战场后”并筛选所在领土，不记作本词条的移动跨界。 |
| **造成或受到伤害后** {#造成或受到伤害后} | 观察来源造成伤害或目标实际受伤。 | 来源或受击者、数值门槛、伤害原因；读取何种伤害量。 | 受伤触发要求实际扣除生命，圣盾／护甲全挡不触发；伤害计数不含防护抵挡与过量部分，见[6.1.2](../../lifecycle.md#伤害事实与多段伤害)；发生前与发生后须写明。 |
| **伤害被抵挡后** {#伤害被抵挡后} | 观察伤害被防护抵挡。 | 对象、防护来源、是否要求全部抵挡。 | 部分抵挡与全部抵挡不同；不能从“未减少生命”推断攻击被取消。见[6.1](../../lifecycle.md#伤害护甲与治疗)。 |
| **实际治疗后** {#实际治疗后} | 观察生命因治疗实际回复。 | 治疗者或被治疗者、数量门槛、是否读取回复量。 | 标称治疗量不等于实际回复量；零回复口径见[6.1.3](../../lifecycle.md#护甲与治疗)。 |
| **死亡与击杀** {#死亡与击杀} | 死亡观察死者；击杀还需要确定致死来源。 | 选择哪种含义、相关对象、原因；所需死亡格等信息。 | 先清理本体再结算死亡效果，见[6.3](../../lifecycle.md#死亡与消灭)；击杀归给直接致死来源，无来源死亡不授予玩家击杀。 |
| **阶段开始或结束** {#阶段开始或结束} | 观察指定阶段的起止。 | 阶段、开始或结束、所属玩家；同步阶段则明确观察范围。 | 新设计优先使用时停阶段开始；你的时动与对方时动不同。阶段见[第三章](../../rounds.md)，选择仍受[操作窗口](../../actions.md#操作窗口)约束。 |
| **购买事件** {#购买事件} | 区分购买声明、成功购买和被取消。 | 准确节点、购买者、所购牌、类型或费用等筛选。 | 购买成功不表示牌一定进入购买者弃牌堆，可能有目的地改写；声明与取消的边界见[5.4](../../economy.md#购买卡牌)。 |
| **星能变化后** {#星能变化后} | 观察获得、支付或其他星能变化。 | 玩家、原因、方向、数量；读取变化前后值或变化量。 | 余额减少不自动等于支付；见[星能](../../economy.md#星能)。 |

## 7.6.1.2 需要区分发生前与发生后的条目

| 词条 | 含义 | 需填参数 | 简例与边界 |
| --- | --- | --- | --- |
| **攻击事件** {#攻击事件} | 攻击前、声明后、取消后、结算完成是不同事件。 | 准确节点、攻击者或受击者、关系和附加筛选。 | 例如天元防壁要在攻击结算前阻止攻击；攻击完成不保证伤害发生。节点及反制细则见[4.4](../../actions.md#攻击与反击)与[第八章](../../effects.md)。 |
| **效果发动或状态变化** {#效果发动或状态变化} | 区分效果发动前、成功发动、状态获得和失去。 | 精确事件、效果来源或状态、观察主体。 | 获得圣盾只在无变有时产生状态获得事件；重复赋予仍可成功执行，但不重复获得。见[圣盾](../../../reference/keywords.md#圣盾)。发动成功不等于主体执行完成。 |
| **拟发生的事件** {#拟发生的事件} | 观察或匹配一项尚未完成的结算。 | 事件种类、拟定对象与参数；若是替换，再写改写内容。 | 发生前触发会发动并执行内容；[结算替换](../replacement.md)直接改写匹配结算，不另发动一份主体。两者不可混用。 |

> [!DETAILS] 词条不是单卡可自定的结算时点
>
> 选择“攻击前”或“转区前”描述监听节点，不等于可以打断任何中间步骤。多项效果的先后、发生前触发对原行动的影响，以及取消后保留哪些事实，统一由[第八章](../../effects.md)裁定。未决边界不能靠给效果填写一个优先级数字解决。
