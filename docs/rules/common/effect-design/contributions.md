先按[7.3](continuous.md)写好持续效果的期限、条件和作用范围，再选择下列作用并填写参数。一份持续效果可以提供多项作用；伤害、抽牌等执行结果见[7.5](execution.md)，不在这里另立为与主动能力平级的效果种类。

| 作用 | 设计内容 | 真实卡牌例子 |
| --- | --- | --- |
| [7.4.1 触发效果](triggered.md) | 监听的事件、事件主体与范围、筛选条件、匹配后的执行内容。 | 星能石、天元防壁。 |
| [7.4.2 结算替换](replacement.md) | 将发生的事件满足什么条件，以及直接改写成什么结果。 | 飞船失火！、魔法练习人偶。 |
| [7.4.3 属性修正](#属性修正) | 修正哪项属性、如何计算，以及属于属性定义还是附加修正。 | 传奇舰长德雷克、小机器人-突击型。 |
| [7.4.4 结算数值修正](#结算数值修正) | 哪种结算中的哪项数值增加、减少或以指定方式变化。 | 阳炎信徒。 |
| [7.4.5 移动规则](#移动规则) | 对哪些移动改变路径方式、目的地或支付规则。 | 火箭动力、飞升之剑-烬白。 |
| [7.4.6 放置规则](#放置规则) | 增加哪些合法落点，或限制来源箭头能支持什么牌。 | 军团登陆艇、帝国基建小队。 |

触发和替换的填写说明在各自子页；其余四种作用在本页。共用外层条件并不表示它们按表格顺序结算。

## 7.4.3 属性修正

属性修正改变作用对象的属性。它可以给属性增加一个数值，也可以直接定义某项属性应等于什么；需要与一次性执行“增加护甲”等结果分开。

| 要素 | 必须交代的内容 |
| --- | --- |
| 属性 | 攻击、生命、移动等明确属性；生命上限、当前生命不能混写。 |
| 运算 | 增加／减少，或设为某值；不能只写“强化”。 |
| 数值依据 | 固定数值，或由当前局面计算的值；计算范围与排除对象要明确。 |
| 修正性质 | 属于这项属性的定义值，还是叠加在既有属性上的修正。两者冲突时不靠文字先后决定。 |

「传奇舰长德雷克」的攻击加成属于附加修正。「小机器人-突击型」的攻击等于其他友方小机器人的数量，属于属性定义；“其他”排除自身，计数范围和“小机器人数量”的口径必须明确。

「小机器人-统御型」用同一份持续效果向范围内符合条件的小机器人同时提供攻击、生命、移动三项修正。多项属性需要各自的运算和数值，不能因为卡面简写为“+1/+1/+1”就漏掉其中一项。

动态数值应说明取什么对象或标记的数量；静态数值则直接写值。属性组合、当前值与上限联动的主定义见[6.2 属性修正与状态](../lifecycle.md#属性变化)，尚未裁定的计算顺序不能由单张卡擅自确定。

**填写顺序：** 所属持续效果 → 属性 → 运算 → 固定数值或计算公式 → 定义值／附加修正。

## 7.4.4 结算数值修正

这类作用修改某一种结算使用的数值，不直接修改卡牌的攻击、生命等属性。

| 要素 | 必须交代的内容 |
| --- | --- |
| 结算种类 | 要修改的是哪种资源收益、伤害或其他已定义数值；不能笼统写“所有数值”。 |
| 对应资源或数值 | 若针对资源收益，指定资源；若针对其他数值，明确其语义。 |
| 运算与数值 | 增加、减少等明确计算方式，以及数值大小。 |
| 适用对象 | 由外层作用范围确定谁的相关结算受到修正，不能误写成直接给他们同量资源。 |

「阳炎信徒」使自身提供的充能收益增加 1；其超新星形态将相应作用提供给周围 3×3 范围内的友方单位。前者与后者主要改变外层范围，内层都是对特定资源收益数值的增加。它不是“每次更新光环便直接获得 1 充能”。

此例用于说明设计已有的数值修正方式；充能本身的归属、取得与消耗仍须完成对应资源定义，不能从“+1”推导出完整资源规则。多个数值修正、取整及替换的先后见[第八章](../effects.md)。

**填写顺序：** 所属持续效果 → 被修正的结算数值 → 对应资源 → 运算与数值。

## 7.4.5 移动规则

移动规则改变对象可采用的移动方式或相关支付，执行一项主动能力使卡牌移动则属于[执行内容](execution.md)。三种通用移动方式的主定义在[4.3 移动](../actions.md#移动与特殊位移)，本节只规定特殊移动作用要写哪些参数。

| 形式 | 必须交代的参数 | 真实卡牌例子 |
| --- | --- | --- |
| 支付资源扩展移动 | 谁支付、支付哪种资源、每份资源数量、对应增加的格数、能否超过当前剩余行动值。 | 火箭动力向友方机械提供额外付费移动。 |
| 瞬移移动 | 单次行动点成本、最大距离、候选格范围与限制。 | 飞升之剑-烬白可向距离 4 以内符合资源格条件的格子瞬移。 |

外层作用范围决定哪些随从获得移动规则；这里的目的地范围决定它们可以去哪里，不能合并成一个“范围”。瞬移依已确认通则消耗 1 行动点，无视途中的碰撞；目标格仍必须满足具体规则。资源可以共存不等于该格没有卡牌，范围条件须按[第二章](../elements.md)使用“空格”和“资源格”。

**填写顺序：** 所属持续效果 → 改变哪项移动规则 → 支付／距离参数 → 合法目的地与其他限制。

## 7.4.6 放置规则

放置规则可以增加合法目的地，也可以限制某些箭头能支持的卡牌。放置与建造的主定义在[4.2](../actions.md#放置与箭头)。

| 形式 | 必须交代的参数 | 真实卡牌例子 |
| --- | --- | --- |
| 增加合法落点 | 适用卡牌的筛选、新增格子范围、按谁的箭头判断、是否允许超出己方领土。 | 军团登陆艇允许海盗使用它指向的格子，包括非友方领土。 |
| 限制来源箭头 | 哪个来源的箭头受限、允许支持哪些目标卡牌。 | 帝国基建小队的箭头只支持建筑；小机器人的箭头只支持小机器人。 |

“能放到这些格子”只修改明示的落点限制，不自动免除其他有效要求或成本。“限制本牌的箭头”也不表示其他来源的箭头同时失效。

**填写顺序：** 所属持续效果 → 增加落点／限制箭头 → 适用卡牌 → 格子或箭头范围 → 领土等明示例外。
