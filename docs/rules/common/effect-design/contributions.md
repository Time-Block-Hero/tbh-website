先按[7.3](continuous.md)写好持续效果的期限、条件和作用范围，再选择下列作用并填写参数。一份持续效果可以提供多项作用；伤害、抽牌等执行结果见[7.5](execution.md)，不在这里另立为与主动能力平级的效果种类。

| 作用 | 设计内容 | 真实卡牌例子 |
| --- | --- | --- |
| [7.4.1 触发效果](triggered.md) | 监听的事件、事件主体与范围、筛选条件、匹配后的执行内容。 | 星能石、天元防壁。 |
| [7.4.2 结算替换](replacement.md) | 将发生的事件满足什么条件，以及直接改写成什么结果。 | 飞船失火！、魔法练习人偶。 |
| [7.4.3 属性修正](#属性修正) | 修正哪项属性、如何计算，以及属于属性定义还是附加修正。 | 前线之光-阿尔德。 |
| [7.4.4 结算数值修正](#结算数值修正) | 哪种结算中的哪项数值增加、减少或以指定方式变化。 | 「黑手」供货商-奇莫的商品费用减半。 |
| [7.4.5 移动规则](#移动规则) | 对哪些移动改变路径方式、目的地或支付规则。 | 海燕、星航恶兆-巨鳐。 |
| [7.4.6 放置规则](#放置规则) | 增加哪些合法落点，或限制来源箭头能支持什么牌。 | 军团登陆艇、帝国基建小队。 |

触发和替换的填写说明在各自子页；其余四种作用在本页。共用外层条件并不表示它们按表格顺序结算。

## 7.4.3 属性修正

属性修正改变作用对象的属性。它可以给属性增加一个数值，也可以直接定义某项属性应等于什么；需要与一次性执行“增加护甲”等结果分开。

| 要素 | 必须交代的内容 |
| --- | --- |
| 属性 | 攻击、生命、移动等明确属性；生命上限、当前生命不能混写。 |
| 运算 | 增加／减少，或设为某值；不能只写“强化”。 |
| 数值依据 | 固定数值，或由当前局面计算的值；计算范围与排除对象要明确。 |
| 修正性质 | 属于这项属性的定义值，还是叠加在既有属性上的修正。两者冲突时不靠文字先后决定。 |

「前线之光-阿尔德」的攻击加成属于附加修正。若设计以数量计算属性的效果，必须明确计数区域、类别以及是否包括自身；“增加 N”与“设为 N”使用不同运算。

多项属性需要各自的运算和数值。例如「金扳手」工程师一次赋予的 buff 同时增加攻击与速度；不能把其中一项遗漏，也不能将其改写为来源离场便消失的光环。

动态数值应说明取什么对象或标记的数量；静态数值则直接写值。属性组合、当前值与上限联动的主定义见[6.2 属性修正与状态](../lifecycle.md#属性变化)，运算次序引用[8.4.1](../effects.md#数值运算与读值)。

**填写顺序：** 所属持续效果 → 属性 → 运算 → 固定数值或计算公式 → 定义值／附加修正。

## 7.4.4 结算数值修正

这类作用修改某一种结算使用的数值，不直接修改卡牌的攻击、生命等属性。

| 要素 | 必须交代的内容 |
| --- | --- |
| 结算种类 | 要修改的是哪种资源收益、伤害或其他已定义数值；不能笼统写“所有数值”。 |
| 对应资源或数值 | 若针对资源收益，指定资源；若针对其他数值，明确其语义。 |
| 运算与数值 | 增加、减少等明确计算方式，以及数值大小。 |
| 适用对象 | 由外层作用范围确定谁的相关结算受到修正，不能误写成直接给他们同量资源。 |

例如「黑手」供货商-奇莫令专属商店格商品费用减半，这是购买费用的数值修正，不是先向玩家赠送一半价格的星能。专属格的其他行为仍由第五章裁定。

多个数值修正、取整与读值统一见[8.4.1](../effects.md#数值运算与读值)，不能用单个示例补出另一种资源系统。

**填写顺序：** 所属持续效果 → 被修正的结算数值 → 对应资源 → 运算与数值。

### 7.4.4.1 法术伤害加成

**作用对象（已确认）。** 未指定对象的“法术伤害＋X”向该效果所属玩家控制的全部法术牌提供加成，例如日光上师。明确选择某张法术的加成只作用于该牌，例如日珀蜂蜜。默认增加这些法术效果造成的伤害，不增加随从普通攻击、治疗或抽牌；教徒的智慧明确令抽牌数量享受法术伤害加成，按其例外处理。

**多目标、多段与分配（已确认）。** 先修正卡文规定的伤害数值，再按卡文分配或重复；不把一次总量拆成的每一点再次加成。

| 原效果 | 法术伤害＋2后 |
| --- | --- |
| 造成3点伤害 | 造成5点伤害。 |
| 对所有目标各造成3点伤害 | 每个目标受到5点伤害。 |
| 随机分配6点伤害 | 总量为8，按[分配规则](../effects.md#随机选择与随机伤害)逐点取样、汇总后同批结算，不将每一点变成3点。 |
| 连续造成两次3点伤害 | 连续造成两次5点伤害。 |

加成后的伤害仍须经过适用的替换和防护，不等于实际扣血量；魔法练习人偶的转换读值见[7.4.2](replacement.md#改写的边界)。

### 7.4.4.2 效果提供的数值

**数值放大的范围（已确认）。** 发电站、超级核电站与超载运转所称“效果提供的数值＋X”，增加效果提供的伤害、治疗、护甲、星能、抽牌数量，以及直接赋予的属性增量。它不改变费用、范围、目标数量、发动次数、进度目标或持续时间；计数条件也不因此改写。

**数值放大效果不再放大其他数值放大效果的幅度。** 两座发电站不会相互提高对方“效果提供的数值＋1”中的1；超级核电站的＋3也不受这种放大。箭头层数加成与效果数值放大是分别写明的两项作用；前者按[2.5.2](../elements.md#箭头层数与点亮)使用，只增强已点亮方向，不自动点亮新方向。

例如星能采矿场原本获得1星能，受到＋1放大时获得2星能；一次直接赋予＋2攻击的效果受到＋1放大时赋予＋3攻击。多个独立来源贡献的加减，沿用[8.4.1](../effects.md#数值运算与读值)计算，不通过来源互相强化反复扩大幅度。

## 7.4.5 移动规则

移动规则改变对象可采用的移动方式或相关支付，执行一项主动能力使卡牌移动则属于[执行内容](execution.md)。三种通用移动方式的主定义在[4.3 移动](../actions.md#移动与特殊位移)，本节只规定特殊移动作用要写哪些参数。

| 形式 | 必须交代的参数 | 真实卡牌例子 |
| --- | --- | --- |
| 路径例外 | 哪些途中障碍可忽略；目的格限制是否改变。 | 海燕移动时忽略卡牌阻挡；未明示改变的终点占格规则仍适用。 |
| 瞬移移动 | 单次行动点成本、最大距离、候选格范围与限制。 | 星航恶兆-巨鳐以瞬移替代步行，到敌方单位相邻的合法格子。 |

外层作用范围决定哪些随从获得移动规则；这里的目的地范围决定它们可以去哪里，不能合并成一个“范围”。瞬移移动行动消耗1行动点，效果造成的瞬移不扣被移动者行动点，见[4.3.5](../actions.md#效果位移与移动计数)；两者均无视途中碰撞，目标格仍必须满足具体规则。资源可以共存不等于该格没有卡牌，范围条件须按[第二章](../elements.md)使用“空格”和“资源格”。

**填写顺序：** 所属持续效果 → 改变哪项移动规则 → 支付／距离参数 → 合法目的地与其他限制。

## 7.4.6 放置规则

放置规则可以增加合法目的地，也可以限制某些箭头能支持的卡牌。放置与建造的主定义在[4.2](../actions.md#放置与箭头)。

| 形式 | 必须交代的参数 | 真实卡牌例子 |
| --- | --- | --- |
| 增加合法落点 | 适用卡牌的筛选、新增格子范围、按谁的箭头判断、是否允许超出己方领土。 | 军团登陆艇允许反抗军使用它指向的格子，包括非友方领土。 |
| 限制来源箭头 | 哪个来源的箭头受限、允许支持哪些目标卡牌。 | 帝国基建小队的箭头只支持建筑；帝国军工厂的箭头不能支持建筑。 |

“能放到这些格子”只修改明示的落点限制，不自动免除其他有效要求或成本。“限制本牌的箭头”也不表示其他来源的箭头同时失效。

**填写顺序：** 所属持续效果 → 增加落点／限制箭头 → 适用卡牌 → 格子或箭头范围 → 领土等明示例外。
