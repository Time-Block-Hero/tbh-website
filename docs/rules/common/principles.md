**第一章草案 · 待审阅。** 本章依据旧规则书和已确认的编写范围整理；下列条款尚待用户审阅，不因写入 Wiki 而自动生效。来源及待确认边界见[第一章审阅记录](../maintenance/pending.md#第一章审阅事项)。

本章规定规则的适用范围、用语和解释方式。行动如何完成、效果如何排序，分别由对应章节详细定义。

## GEN-001 适用范围

通用游戏规则定义所有模式共享的星能运营、卡组成长、棋盘对弈、回合流程和商店购买，以及这些玩法所需的游戏要素、行动与结算规则。

一局游戏采用所选模式的规则，并同时适用通用游戏规则。模式规则负责补充该模式的对局目标、构筑与开局配置、自动机制，以及明确列出的例外。模式规则没有另作说明的事项，继续适用通用规则。

当前编写的模式为[标准对战](../standard/overview.md)。未来新增模式分别说明自己的补充与例外，不改变其他模式的规则。

## GEN-002 规则用语

| 用语 | 含义 |
| --- | --- |
| 必须 | 满足适用条件时，规则强制执行，玩家不能自行省略。 |
| 可以 | 规则允许但不强制；由有权作出该选择的玩家决定是否执行。选择执行时，仍须满足适用条件与成本。 |
| 不能 | 在该限制适用时，不允许执行指定行为或发生指定变化。 |
| 通常／默认 | 没有适用的特殊规定时采用的基础处理方式。 |
| 除非……另有说明 | 只有适用条款明确作出不同规定时，才按该规定处理。 |

“可以”不会自行免除成本或其他限制；“不能”也不在这里被赋予凌驾于一切规则的绝对优先权。发生冲突时，按下文的规则优先关系和具体机制的规定处理。

## GEN-003 规则优先关系

当多项适用规则能够同时满足时，应同时适用。只有它们对同一事项给出无法同时成立的要求时，才需要判断优先关系。

不同来源的规则发生冲突时，按以下顺序，由前者优先于后者：

1. 当前适用的模式或关卡规则。
2. 具体卡牌文本、英雄技能文本和地图物件文本。
3. 关键词与状态规则。
4. 基础规则与通用结算规则。

引用某条通用规则，或者填入该规则允许模式指定的数值，本身不构成冲突。

操作提示、日志和视觉表现用于帮助理解局面，不能改写规则。表现与规则不一致时，按适用的游戏规则判断。

以上顺序用于判断不同规则来源的关系，**不代表效果的执行先后**。多个效果如何排序、替换和触发，见[效果与结算时序](effects.md)。同一层级的冲突不能仅凭这张顺序表裁定，也不能自行按卡牌稀有度、文本长短或出现先后来决定。

## GEN-004 明确例外及其边界

卡牌或其他适用规则写明“无视”“改为”“不能”“额外”等规定时，按它明确改变的事项处理，并遵守上述优先关系。

例外只作用于它说明的对象、条件、范围和时限。没有被改变的规则仍然适用。

例如，一张牌只写明“无视箭头需求”，这段文字只改变箭头需求本身，不能据此推断它还允许无视领地、占格、阶段或成本限制。这是解释例外范围的示例，不预先确定各项放置限制的具体内容。

如果文本只描述结果，没有明确改变相关规则，则按实现该结果所适用的通用规则处理。费用、选择、取消和失败的具体后果，统一见[效果与结算时序](effects.md)，不从一个省略的词语推断额外特权。

## GEN-005 关键词与规则引用

关键词是具有固定规则含义的简写。卡牌或规则使用关键词时，按[关键词库](../reference/keywords.md)中该词条的定义理解；关键词库是共用规则的一部分。

每个关键词只维护一处完整定义。正文在需要的位置链接该词条，并说明它与当前流程的关系。例如，放置章节涉及[入场](../reference/keywords.md#入场)时，引用“入场”词条；该关键词的触发条件和专属例外在词条中定义，多项效果的顺序则引用结算章节。

卡牌对某个关键词明确规定例外时，依 GEN-003 与 GEN-004 判断其适用范围。没有明确改写的部分继续适用词条定义。

关键词名称本身不能替代尚未完成的定义。目前仍为草稿的词条，须在确认后才能作为正式裁定依据。

## GEN-006 时间与结算范围

**本回合**：从当前回合开始，到该回合结束时所有应完成的清理全部完成为止。回合内部的阶段、权限和转换条件见[回合流程与行动权限](rounds.md)。

**本次结算**：从某一次行动、效果或对局自动流程开始处理，到该过程及按规则应在此次过程中处理的后续结算完成为止。为其他时点安排的效果，不因由此过程安排而自动计入本次结算。具体范围、后续效果如何插入及何时返回原过程，见[效果与结算时序](effects.md)。

“本次结算”说明所指过程的范围，本身不改变其他玩家的行动权限；其他玩家能否同时操作，仍按当前阶段和具体规则判断。

当规则写明更具体的生效或结束时点时，按该时点处理。“本回合”这一范围不代替回合末效果、临时状态到期和清理之间的先后规定。
