**第一章修订稿。** GEN-003 至 GEN-005 的有效性、明确例外及关键词同等效力原则已在本次讨论确认；其他条款与细节继续审阅，整页暂保留草稿状态。来源及待确认边界见[第一章审阅记录](../maintenance/pending.md#第一章审阅事项)。

本章说明怎样理解和共同应用游戏规则。它不按卡牌、关键词、状态或模式的来源给规则排等级。行动如何完成、效果如何排序，分别由对应章节详细定义。

## 1.1 GEN-001 适用范围

通用游戏规则定义所有模式共享的星能运营、卡组成长、棋盘对弈、回合流程和商店购买，以及这些玩法所需的游戏要素、行动与结算规则。

一局游戏采用所选模式的规则，并同时适用通用游戏规则。模式规则负责补充该模式的对局目标、构筑与开局配置、自动机制，以及明确列出的例外。模式规则没有另作说明的事项，继续适用通用规则。

当前编写的模式为[标准对战](../standard/overview.md)。未来新增模式分别说明自己的补充与例外，不改变其他模式的规则。

基础规则是游戏共同采用的处理方式：满足规定条件时，就按该规则执行，除非有明确适用的例外。基础规则可以带条件，例如具有护甲时如何处理伤害。

具体卡牌写明“造成 3 点伤害”，是在给出该效果的具体内容；这本身不改变通用伤害流程。模式规定自动机制的时间、位置和数量，也不因此自动绕过对应的通用结算。

## 1.2 GEN-002 规则用语

| 用语 | 含义 |
| --- | --- |
| 必须 | 满足适用条件时，规则强制执行，玩家不能自行省略。 |
| 可以 | 规则允许但不强制；由有权作出该选择的玩家决定是否执行。选择执行时，仍须满足适用条件与成本。 |
| 不能 | 在该限制适用时，不允许执行指定行为或发生指定变化。 |
| 通常／默认 | 没有适用的特殊规定时采用的基础处理方式。 |
| 除非……另有说明 | 只有适用条款明确作出不同规定时，才按该规定处理。 |

“可以”不会自行免除成本或其他限制；“不能”也不在这里被赋予凌驾于一切规则的绝对优先权。发生冲突时，按下文的规则优先关系和具体机制的规定处理。

## 1.3 GEN-003 有效性与规则优先关系

**先判断规则或效果是否适用、有效，以及是否满足其发动或生效条件；再由有效且适用的明确例外，改变对应的通用处理。例外没有改变的部分，仍遵循通用规则。**

对同一事项，优先关系为：**有效且明确适用的例外规定，优先于通用规则的默认处理。**

按以下次序判断：

1. 确定当前局面适用哪些规则，以及相关效果是否仍有效、能否在此时发动或生效。
2. 按通用规则确定通常的处理方式。
3. 应用有效且适用的明确例外，只改变它明确说明的部分。
4. 对没有被改变的部分，继续按通用规则处理。

卡牌、关键词、状态、模式或关卡的来源，本身不赋予更高优先级。多个有效规则能够同时满足时，应同时适用。

某条适用规则可以使一个效果失效或不能发动；该效果未能生效时，也就不能提供它原本会产生的例外。这里仍须区分“禁止主动发动”和“使持续效果失效”，具体范围由对应规则定义。

例如，假设关卡使怪兽处于某种状态，且该状态明确封锁了它的“无视护甲”效果：该效果无法参与本次伤害结算，就没有产生无视护甲的例外，伤害仍受护甲影响。如果该状态只禁止主动发动，不能由此自行推断它也封锁持续生效的能力。本例不预先确定[沉默](../reference/keywords.md#沉默)的完整范围。

若两个有效且适用的例外彼此冲突，本条不能独自裁定结果；应使用相应的交互规定和[结算时序](effects.md)，不能仅凭来源、稀有度、文本长短或展示先后决定。

游戏规则优先于操作提示、日志与视觉表现；后者不能创设或改写规则。

## 1.4 GEN-004 明确例外及其边界

例外必须明确指出改变的事项，并只作用于其说明的对象、条件、范围和时限。没有被改变的规则仍然适用。

- “此次伤害无视护甲”改变护甲对这次伤害的处理；没有同时写明无视[圣盾](../reference/keywords.md#圣盾)，就仍须遵循圣盾规则。
- [保留](../reference/keywords.md#保留)使该牌免于回合结束时的手牌弃置；它没有自动免除其他原因的弃牌。
- “放置时无视箭头需求”只改变箭头需求，不能据此推断它还允许无视领地、占格、阶段或成本限制。

文本只描述结果而没有改变相关规则时，按产生该结果所适用的通用规则处理。费用、选择、取消和失败的后果由对应机制规定，不从省略的文字推断额外许可。

## 1.5 GEN-005 效果、关键词与状态

[效果](elements.md#效果关键词与状态)规定卡牌如何影响游戏；关键词是效果规则的标准化简写；状态记录卡牌在对局中持续具有的特殊情况、标记或累计数值。

**关键词的简写与其完整描述具有同等规则效力。** 写“圣盾”和写出同一圣盾规则，不会产生优先级差别。

关键词的完整规则统一维护在[关键词库](../reference/keywords.md)。正文在需要的位置引用词条，例如[放置](actions.md#放置与箭头)引用[入场](../reference/keywords.md#入场)，再由结算章节说明多个效果的顺序。

一个词可以同时是关键词名称和状态名称：卡面上的“圣盾”简写能力；“当前具有圣盾”描述状态。状态怎样影响结算，由相应规则定义，不另占一个优先级。

目前尚未完成或确认的词条明确标记其边界，不能仅凭名称补出未写明的行为。

## 1.6 GEN-006 时间与结算范围

**本回合**：从当前回合开始，到该回合结束时所有应完成的清理全部完成为止。回合内部的阶段、权限和转换条件见[回合流程与行动权限](rounds.md)。

**本次结算**：从某一次行动、效果或对局自动流程开始处理，到该过程及按规则应在此次过程中处理的后续结算完成为止。为其他时点安排的效果，不因由此过程安排而自动计入本次结算。具体范围、后续效果如何插入及何时返回原过程，见[效果与结算时序](effects.md)。

“本次结算”说明所指过程的范围，本身不改变其他玩家的行动权限；其他玩家能否同时操作，仍按当前阶段和具体规则判断。

当规则写明更具体的生效或结束时点时，按该时点处理。“本回合”这一范围不代替回合末效果、临时状态到期和清理之间的先后规定。
