## 本轮逐项裁定顺序

当前采用八批审阅：第一批为对象与棋盘，已确认部分写入第二章；范围默认作用于其他随从已补充确认；仅其他效果的箭头计数边界并入第二批，不重新询问已确认项。

2. **数值与状态。** 法术伤害、全属性、数值放大、生命成本、行动恢复。
3. **移动与效果放置。** 强制位移、瞬移计数、召唤条件、落点与部分执行。
4. **回合与结算时点。** 抽牌批次、时动排序、冻结合并、慢速、同时触发。
5. **拾取与归属。** 拾取资格、收益对象、转交卡牌后的归属与受益。
6. **商店与信息。** 刷新、容量、购买失败、奇莫专属格、区域可见性。
7. **苍空与烈阳单卡缺口。** 发动时点、生成目的地、吸取生命等。
8. **天元与机械单卡缺口。** 维拉／革命日、飞升烬白、复制类型等。

批次是审阅主题，不是问题条数，也不意味着整批自动获批。资源类型与重复身份的数据工作另列；第9–11章模式配置和第13章完整案例尚未起草。

### 剩余范围与计数口径

完整覆盖本轮 137 张卡；卡牌数量不等于裁定数量。逐卡表标记“已对照”表示未发现该卡独有的未决参数，仍适用本页列出的共用草案边界；“有未决”会给出实际例子。已撤下的充能、额外时动、时停跨玩家反制不再列为待设计机制。

## 第七章审阅事项

本章组织与字典展示已修正；本次已将过时卡例替换为当前设计。真实缺口见全卡表：

- 法术伤害加成的作用者、适用结果、多段与其他替换的顺序。
- “效果提供的数值”“全属性”“所有卡面数值永久 +1”的确切字段范围及相互放大。
- 发动时点、赋予期限、选择方法、生成目的地、复制类型及数值来源缺失的单卡。

这些是卡牌没有填写完整的设计参数或共用定义缺失；不能通过换一套效果分类消除。
