## 第一章审阅事项

第一章已形成[GEN-001 至 GEN-006 草案](../common/principles.md)，当前尚未确认。请优先检查：

1. **不同来源的优先关系。** 是否继续沿用旧长版的“模式或关卡规则 → 卡牌、英雄技能与地图物件文本 → 关键词与状态 → 基础与通用结算规则”？草案先按旧文整理，不把这个顺序当作本次已批准决定。
2. **同级冲突的边界。** 旧总则没有给出两个同级效果要求不相容时的通用答案，也没有确立“不能”永远压过“可以”。草案明确这一层级表不负责效果时序；具体交互在第七章讨论，不凭字面先后补造结论。
3. **时间用语。** “本回合”覆盖回合末清理；“本次结算”包含此次过程中应完成的后续处理，不自动延长至为其他时点安排的效果。草案不以此取消另一玩家在当前阶段已具有的操作权限。精确的结束时点和交错边界在第三、七章展开。

上述事项随本章审阅修改。程序现状核对仅提供局部机制证据，不自动裁定整套通用规则。
