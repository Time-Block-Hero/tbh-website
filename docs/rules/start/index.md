## 已确认的编写范围

星能运营、卡组成长、棋盘对弈，以及回合流程和商店购买，都是所有模式共享的核心玩法。标准对战单独定义 1v1 的配置和专属规则。未来 Rogue 或剧情模式实际开始设计时，再新增模式章节并引用通用规则。

本版取消高度这一玩法维度。资源共存、玩家控制资格及拾取后消失已确认；其余未定边界不能从旧文档直接沿用。

## 正式规则的目标

给定相同的初始局面、玩家选择和随机结果，仅依据规则书，应能逐步推演出唯一的对局过程与结果。

正文使用游戏语言，明确选择、支付、触发、改写、失败、检查与结束的时点。程序类型、内部结构和执行架构不属于规则正文；规则可以作为工程实现的充分参考。
